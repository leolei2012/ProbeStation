面向嵌入式设备的**观测与测试平台**：监控是数据底座，AI 测试是大脑与核心卖点。
用 DeepSeek Harness（DSH）「一切皆插件」的理念，以 TypeScript + Cordis 全量重写了旧 Monitor（Python FastAPI + Quasar）。

全局保留设置修正失败假显示、迟到读取覆盖及空输入变永久：先读取实际值，选择只改草稿，明确确认才更新；未知结果保留本页状态且阻止重复写。后端旧接口跨用户并发限制仍在。`npm run preview:global-retention`可纯mock手测，见[读写状态回归](docs/develop/62-全局保留策略读写状态回归.md)。

## 离线点表诊断

## 内置 AI 助手

助手富文本解析器按需加载：该阶段首屏主JS构建体积由约536.35kB降为379.68kB，约减少29%（后续功能体积以当前构建为准）；正文资源加载中/失败时保留纯文本，可手动重试，不重发消息或业务操作。已有会话/确认流程保持原装配，实际浏览器速度尚未测量。`npm run preview:markdown`可生成不联网模拟页，体积口径、构建边界和验收限制见[说明](docs/develop/26-助手富文本按需加载.md)。未部署运行实例。

启动后点击左下角 **设置 → AI 助手**，选择第三方提供商并填写 API Key；各提供商的配置分别保存。聊天框右下角可切换提供商的模型和该模型支持的推理等级。底层复用 DSH 使用的 `@earendil-works/pi-ai`（0.87.x）；当前接入 API Key 提供商，尚未接入 OAuth、AWS/Vertex 等云凭据流程。自定义模型 API 保留以下 Chat Completions 接入。
接口使用支持工具调用的 Chat Completions 协议，程序自动在基础地址后追加 `/chat/completions`；例如基础地址可以包含服务商要求的 `/v1`。远程地址要求 HTTPS，本机 `localhost` / `127.0.0.1` 可使用 HTTP 和免密模型服务。不需要额外启动 DSH 或 MCP 客户端。

- **查询**：设备、点位定义、当前缓存值、历史数据、通信统计和最近报文。
- **修改**：设备名称/扫描间隔/超时，分组名称/启停，点位名称/单位/比例/偏移。AI 只生成提案，界面展示目标、新旧值，用户确认后执行并读回验证；配置已被其他操作改变时拒绝执行。支持撤销已确认的配置修改。
- **不开放给内置 AI**：硬件写入、删除、固件升级、任意 shell/SQL/HTTP 调用。现有外部 MCP 的能力不变。
- 选择设备后，对话限定在该设备；切换设备可恢复各自对话。聊天保存在服务器数据目录，支持重启恢复、流式回答、停止和确认/拒绝；输入 `/compact` 可压缩较早上下文。已知模型接近窗口容量时会自动压缩；自定义接口可在设置中填写窗口大小。
- 模型服务会接收对话和按需查询的数据；密钥保存在实际数据目录的 `ai-settings.json`，不会通过设置读取接口返回，也不会放在浏览器 localStorage。该文件不是加密保险库，迁移/备份时须按密钥文件处理。更换 API 地址而未输入新密钥时，旧密钥会清除。
- AI 设置在实例内共享。程序当前仍是无账户鉴权的本地/可信内网工具；同源检查和会话随机 ID 不等同于用户身份认证，不应直接暴露到公网。
- 助手不设固定工具次数、轮数、请求时长、附件数量/大小或历史查询点数/区间限额；模型窗口及服务商配额仍由提供商决定。历史返回原始解码值及语义配置，相邻字按毫秒时间对齐，缺字返回 null。当前值是采集缓存，必须结合样本时间和质量判断。

可试问：“查看当前设备的数据和采样时间”“检查设备通信有没有异常”“把当前设备采样间隔改成 500ms”。首次保存设置后发送一个问题即可验证服务；HTTP 错误会显示在对话面板。

实现入口：`packages/api/src/assistant.ts`（工具循环、配置、会话、确认），`apps/web/src/AssistantPanel.tsx`（侧栏）。网关复用现有 config/store/poller 服务，维护内置助手的工具白名单。工具调用协议参考 [DeepSeek 官方说明](https://api-docs.deepseek.com/guides/tool_calls/)。

本地模拟测试不需要 API Key，也不会调用模型或真实设备：

```bash
npx tsx scripts/test-assistant.ts
npx tsx scripts/test-assistant-history.ts
```

## 隔离只读测试版

运行 `npm run test:edition`，待“隔离只读测试版”日志后访问 http://127.0.0.1:4181/，停止用 Ctrl+C。每次创建新临时库和合成历史，不加载设备通信、轮询、从站或模型服务。仅验收历史表格/曲线/导出，其余写操作禁用。具体场景、验收状态和限制见 [测试说明](docs/test/隔离测试版使用说明.md)。不要用正常主应用入口代替此命令。

设备新增/编辑弹窗的 RTU 连接参数支持后端系统串口清单和刷新，保留手动输入。测试版也使用真实系统的只读端口枚举，设备和历史仍为合成数据；不会打开串口。

串口清单请求超过10秒会取消等待并恢复刷新，保留手工路径与旧清单（标为可能过时），避免一直卡在读取中。只影响界面请求等待，不保证中断后台OS枚举；本轮未实际枚举或打开串口，浏览器未验收，见[串口清单恢复说明](docs/develop/18-串口清单超时与重试.md)。
