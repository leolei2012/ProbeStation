## 实现

GlobalRetentionFlow 初始值为未知，仅接受非负安全整数的后台实际值，不用30天填补错误。读取10秒超时，可显式重新读取；关闭/切换分区取消只读等待，迟到结果不改新状态。App单独为设置注入 AbortSignal 与 no-store，不改变其他 API 或写请求。

预设/自定义只编辑本地草稿；空、负、非整数、非有限数和不安全整数不可提交，明确0为永久。当前值、拟修改值分开展示，核实当前值后才能修改；必须勾选不可撤销历史清理说明并明确确认。打开读取未完成时不能保存，避免旧读取覆盖写入结果。重新读取不覆盖已有草稿，并取消其确认勾选。

更新同步单发，不加写超时/取消或自动重试。10秒只增加等待提示，关闭设置或数据分区不会取消更新；模块级状态由已有延迟加载的ESM缓存保存，重开不会重发。只接受 ok:true 且 retention_seconds 精确匹配的回执，HTTP200中的验证错误体也不能当成功。成功文案仅指上次策略回执，不承诺当前值或清理完成。

抛错、缺回执或回执不匹配均视为结果未知，保留上次核实值并明确其已过期，停止本页进一步写入。仍可只读核对当前值，但读取无法证明旧更新最终是否结束，因此不自动解除写入限制。挂起写入可能一直等待；需要人工核实后台和旧请求状态。状态只在当前页面内存，不跨刷新/标签页/浏览器重启，刷新不是安全重试凭据。

设置依然按需加载；新增模块加入静态依赖隔离守卫，不移入首屏。其余主题/语言、隐藏AI表单、备份/日志入口保持原挂载方式。
