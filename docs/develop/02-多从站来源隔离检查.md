# 多从站相同地址来源隔离检查

> 状态：告警、持久化、缓存、主要只读消费者和录制已接入；写入和实机/UI 验收仍有限制｜2026-11-06

从 73413b5、干净工作区开始，只读源码及内存/mock 复现，没有访问真实配置/历史库、抓取设备报文或连接实机。

## 已核实模型与协议

| 环节 | 事实与风险 |
|---|---|
| 配置 | 点位属于 groupId，分组保存 slaveId；主站读取用分组 slaveId，缺失时既有代码默认 1。本地 slave 模式使用设备自身编号。 |
| 驱动 | FC01/02/03/04 read 方法有 slaveId 参数，TCP 客户端和 RTU 请求均使用此目标编号；驱动返回数据数组。本轮保留调用上下文，不猜测或修改协议，也不声称额外认证物理设备身份。 |
| 原 poller | 请求时知道从站，但 points 只保留设备/数据区/地址/值/时间/batchId/quality，来源丢失。 |
| 原后端规则 | 按数据区/地址/批次选完整字，完整 batchId 不能证明属于目标从站。 |
| 热缓存 | key 为 objectId:area:address，第二个从站覆盖第一个；快照没有来源。 |
| 冷库 | poll_data 没有 slave_id，flush、raw query、分页与曲线都未保留来源。 |
| 前端/助手 | 消费缺来源的快照与历史，前端 WebSocket reducer 也未保留 slaveId；新事件增加字段不等于全链路隔离。 |

## 复现与本次修复

同设备两个分组分别读从站 1、2 的同一数据区相同地址，值为 5、65536，两条规则都比较 >65535。旧 pollOnce 合并事件令两条规则均告警（实际 [1,2]，预期 [2]），回归先失败。

本次 readGroup 每字输出目标 slaveId，pollOnce/轮询沿用原事件结构传递。后端先选目标从站再选完整批，保持同从站重叠组兼容；其他来源不能触发/解除目标告警，多从站下无来源事件及无来源补字被跳过。去重签名增加目标来源，已知来源告警事件携带 slaveId。阈值、实际请求、批次身份及硬件调用不变。

scripts/test-slave-source.ts 通过 mock 驱动覆盖四个读 FC、pollOnce/轮询、32/64 BE/LE、误触发与误恢复、旧事件缺来源、跨从站同 batchId、混入旧字和修改目标从站后的去重；原单从站与同从站重叠分组回归继续通过。

另用内存 DuckDB 复现未修路径：同设备同址写从站 1 值 5、从站 2 值 100，热快照仅剩 100 且无来源；冷库两行来源均缺失，两条同址曲线均得到 [5,100]。这是待修缺陷，没有把错误行为写成必须保持的回归断言。

## 后续阶段完成情况

1. **持久化/热层，7f869d3**：可空 slave_id INTEGER 绑定保存请求目标；旧行保持 NULL，事务迁移验证列定义并幂等，失败回滚并拒绝继续写入。原始四查询/导出和 JSON 往返保留来源；热层按从站键控，无来源别名发生冲突即移除。新临时库/内存测试覆盖旧 register_id、缺 area/batch_id/slave_id、当前库、重开、无损原行、非法类型/默认约束与 DDL 失败。
2. **实时消费者**：REST/WS 保留来源，前端增量采用 sourceKey；首次快照、REST 兜底、表格、实时曲线、健康状态和前端告警均按点位目标取值，来源切换重置曲线缓冲，不将未知或另一从站填进已知目标。来源选择与元数据不一致的缓存项拒绝使用。本地 slave 发布沿用设备自身编号，没有改变通信或生成 batchId。
3. **历史/导出**：register 由当前所属 group 绑定期望 slaveId，本地 slave 模式由设备编号绑定；先筛选目标及 NULL 行，再按精确采样时间验证完整字、同批和质量。已知目标字存在时不补 NULL/其他源；旧 NULL 无歧义时仅兼容查看，跨来源重叠时未知；未绑定目标永不自动已验证。表格、前后端曲线及 CSV/XLSX 共用判定。状态文字扩大为“批次/来源已验证/未验证”，CSV 列名不变。导出按从站/area/地址在 LIMIT+1 前筛选，其他已知从站不占额度，NULL 无法归属则保守计入。内部旧逐地址聚合也已明确停用。
4. **助手/MCP 只读**：快照需完整同批、同一有效采样时间及已知目标，历史只对完整已验证 value 做统计；未验证兼容值单独提供、自动 value 为 null。原始 MCP 多字历史仍未知，单字遵循同样来源策略。按 area/address 无法唯一定位时返回候选，可用 slave_id/register_id 精确选点，条件冲突拒绝而不隐式换源。通过 mock 模型网关和 MCP 注册器验收，无真实模型或传输监听。
5. **数据缺口**：旧历史缺失的来源无法恢复，没有回填或迁移真实数据。当前分组改从站后，历史随当前目标筛选，不把原来源改名；原始接口仍可查看旧已知来源。来源为请求上下文，不是额外物理身份认证。
