# 选点核对组合与来源变化保护

## 复现与修复

基于cab5902组合检查发现：共享选点弹窗按点位ID保留草稿，打开期间同一组/点位编号的从站变更后，原保存仍可应用旧ID，新列表还会把新来源勾选为原选择。观察清单调用方已有范围保护，但历史页、曲线使用的共享弹窗没有统一拦截。新回归在修复前因保存按钮仍可用而失败。

现在记录弹窗打开时所能看到的选项定义：分组ID/名称、有效配置从站（本地从站使用设备覆盖值）、点位ID/别名/地址/FC/类型及选择上限。比较按ID排序的副本，不修改输入；等价刷新和列表重排不会丢失草稿。数据变化一旦在本弹窗被观察到，草稿即失效，即使改回原值也不会自动解禁。

失效时隐藏可选行，禁止编辑及应用，显示中英文关闭重选提示；不将旧编号勾选到新来源。保存回调读取同一失效标志，所以此前捕获的旧保存回调同样被拒绝。取消、叉号和Escape仍可关闭，不调用onApply；重新打开按调用方当前已选值创建新草稿。

这是页面已接收选项的保护，不是服务器版本锁；不能检测尚未同步的后台变化或两次刷新之间未观察到的往返变更。未传给选点器的配置字段不参与判断，也不推断未知来源。实际设备页按设备ID挂载，观察清单仍保留原范围保护；没有改变采集、历史解码、选择存储格式或API。
