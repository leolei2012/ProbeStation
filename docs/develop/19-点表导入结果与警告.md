# 点表导入结果与警告

状态：已实现，完整离线检查通过；浏览器验收未完成。日期：2026-11-06。

## 用户流程问题

XLSX导入后端已有从站/范围推导等兼容警告，也会将“已经提交，但通知或日志失败”作为warnings返回。原Web上传流程只检查errors并弹出通用成功通知，warnings全部丢失，用户无法核对默认值，也难以分清已提交后的提示与需要重新导入的失败。

本轮在配置工具栏下新增结果面板，保留文件名、分组/点位数量、所有错误和警告，直到用户关闭、再次导入或离开该设备表格视图。观察/配置模式切换不会主动清除。长内容可滚动并键盘聚焦，文本按纯文本转义显示。

## 状态契约

- 无errors的合法报告显示完成，即使有warnings；已提交后的通知/日志警告不被改成导入失败。
- errors且报告计数均为0显示未完成；同时有非零计数和errors的兼容报告标记结果待核实，不猜测是否回滚。
- 网络/HTTP异常、非法JSON或报告字段缺失/类型错误标为待核实，提示配置可能已更新，先检查当前配置再决定是否重新导入。不将不确定返回当作“未写入”。
- 接受旧报告缺少可选warnings，默认空列表；数量必须是非负安全整数，errors/warnings必须是字符串数组。复制白名单字段，不修改响应或点表。
- 仍按已有端点发送一次POST、沿用原替换行为；不增加自动重试、写请求超时/取消、数据库变更、预导入或新协议。结果面板是对服务器报告的展示，不是配置读回核验或防重复事务机制。

## 验证

新增 `scripts/test-pointbook-result.ts`，先复现警告未显示再修复。纯SSR和mock fetch覆盖文件名/计数/全部警告、完成/拒绝/不确定、旧报告/非法字段、HTML转义、无隐式关闭/重试、原POST路径与二进制body及网络失败仅请求一次。

同脚本使用新建`:memory:`配置库和生成的XLSX，触发真实从站默认警告及提交后通知失败；确认点位确已写入模拟目标，报告仍为完成且全部警告可见。非法dtype回归显示未完成并保留模拟目标原配置；不读取真实文件或配置库，不开启任何设备通信。

## 限制

实际浏览器的上传选择、关闭面板、长列表滚动、模式切换及窄屏/键盘尚未验收；此前浏览器连接受限，本轮不重试受限原生Edge或扩大权限。测试未通过真实页面上传文件，也未操作实机或真实数据。

面板不跨页面/重启持久化。HTTP异常不能证明事务结果，用户仍须核对；已有写请求如果一直不返回，仍需等待，不能套用只读请求的自动取消/重试策略。本轮未部署或重启现有实例。
