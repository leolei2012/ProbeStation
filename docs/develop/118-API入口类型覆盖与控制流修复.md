## 最小修复

assistant的fail从仅在箭头函数上写返回never，改为给const变量显式的(message, optional statusCode) => never类型，函数体/default400/throw对象原样保留。当前编译器因而识别原来的失败终止，既有find/数组/附件/提案守卫完成收窄；不新增非空断言、any、try绕过或业务分支。

新增API类型模块events.ts，按实际poller、rule、DeviceSlaves生产者声明现有5类包络。group-ok明确保留只有groupId的历史发送形式，objectId可选；device/status保留可选error。poller/result只对中继所需包络作约束，points元素是unknown，不虚构更深的采样验证或物理身份。readOrigin沿用既有AcquisitionOrigin类型，规则值沿用number/string，不新增字段或协议。

index仅type import该声明，原5个中继回调去掉any以接受上下文推断。事件名称、JSON内容、路由及状态码不改；声明不是运行时校验。117号告警装配恢复静态API导入，去掉临时的动态导入覆盖边界，事件观察参数也按新类型推断。

审查将助手和API总入口以同一目标编译后比较运行时JavaScript语法树，均与基线一致；新增事件模块编译仅为空export且不被运行时import。事件声明没有执行代码或新增运行依赖。这是扩大静态覆盖，不是后端业务重写。
