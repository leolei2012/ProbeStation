# 历史曲线 A/B 两点对比

状态：已实现，完整离线检查通过；真实浏览器验收未完成。日期：2026-11-06。

## 功能与使用

原历史曲线已有悬停读数、峰谷和缩放，缺少两个时刻之间的直接比较。本轮增加完整的两点分析流程，不增加设备、模型或其他服务调用。

1. 在设备历史页查询并切到曲线，展开“A/B 两点对比”。
2. 移动指针或轻触图表选择时刻，再点击设置A；可缩放/平移查询更细区间，然后设置B。
3. 查看游标时间差，以及每个点位的A/B实际采样时间、批次/来源状态、数值差和实际采样时间差。差值均为B−A，允许负数或相同时间。
4. 再设A/B可替换该端；清空按钮移除两端。图中竖线标识游标位置，端点实际采样时间以表格为准。

两端为页面内的冻结快照：缩放、同定义的查询刷新不会改写已设端，若要使用放大后的更细采样，应重新设置相应端点。点位选择、图例显隐、所选定义/来源/换算/小数位、原始/物理模式、完整时间范围或显式引用重新定位变化会清空。相对量程只影响绘图，不改变对比读数。

查询过程、失败/取消时面板暂不显示，成功重试后保留同上下文快照和展开状态。缩放到空区间仍保留缩放控制，可重置返回；未设置游标或没有可见点位时禁用设点，无可用采样则捕获未知。

## 数值和身份边界

- 只选实际**显示采样**，不插值、不外推。连续降采样区间选择最近保留点（等距取较早者），因此游标时间与实际时间可以不同；不能把此差值称为精确游标时刻的值。
- 优先沿用已有源分段；分段断线、无效边界、无连续性证据、乱序/重复样本或无数据返回未知，不跨缺口选值。无间隔证据时仅接受准确采样时刻。新边界回归曾复现无效边界误选邻近值，已修复。
- 每行按点位ID独立比较，复用配置身份标签区分同名/同地址不同来源；不在不同点位之间做减法。已验证、未验证和未知状态保持原样。兼容未验证端点可查看差值，不能作为自动PASS/FAIL依据。
- 不计算合格判定、变化率或阈值结论。未知端点或非有限差值不生成数值结果。计算使用未舍入的曲线数值，显示沿用当前数值格式/小数位和工程单位；相对量程不参与计算。受现有曲线浮点及安全整数精度限制，不能代替原始数据计量。
- 快照只存在当前图表内存，不跨页面保存，不写入配置/历史，不进入CSV/XLSX或AI上下文；未新增后端接口、数据库迁移或依赖。

## 离线手测

在项目目录运行 `npm run preview:comparison`，手动打开 `output/playwright/history-comparison-preview.html`。文件自包含、禁止联网，无端口、数据库、模型或设备；关闭页面即可停止。正式对比组件与计算逻辑复用，模拟图和滑块仅用于手测，不是完整历史页面。

模拟数据：1秒设A、4秒设B，原始差值两行应为20/40、实际间隔3秒；第二行显示未验证。反向设置检查负差；2秒或断线区间不产生差值。切为物理值清空后重设，差值应为2/4℃；切换全无效数据不改旧快照，重新设点得到未知。切查询中/失败再恢复，检查快照和展开状态。检查清空、长标签/不同来源以及360px窄屏。原picker/settings预览保持兼容。

真实浏览器的指针/触摸、标记位置、面板展开保持、空区间恢复、窄屏及完整App集成未验收；此前浏览器连接受限，本轮不重试受限原生Edge或扩大权限。静态生成、JS语法、SSR及状态测试不能替代DOM点击。本轮不启动、部署或重启采集/现有测试服务，也不读取或修改真实数据。
