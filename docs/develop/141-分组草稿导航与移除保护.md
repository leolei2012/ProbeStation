## 行为

LiveTable 将既有 draftScope 传给按需加载的分组表单，表单显示后登记分组草稿；加载代码期间没有新表单或草稿，也不会自动读取/写入配置。DraftNavigation 新增 group 类型：它随实时页卸载，因此既参与设备/全局切换的 all 检查，也参与离开实时页的 live 检查；设备编辑器仍不受不卸载它的局部页签干扰。多个点位/分组编辑器共享每次导航的一次确认，取消即保留全部输入；保存未决时直接阻止离开或删除，不允许确认覆盖。

比较的是打开时与当前原始字段文本，包括空或尚未合法的数字输入，不能因校验失败把草稿当作无变化。普通配置刷新、快照读取失败/迟到不会重置这些文本；恢复原值且未保存时不会虚构脏状态。分组关闭按钮与 Escape 使用浏览器确认，取消继续编辑，输入法组合中的 Escape 不关闭；保存进行中禁止关闭。关页/刷新复用已有 beforeunload 风险提示，无草稿/未决保存时不注册提示。

**这些都是当前页内存保护，不是持久保存。** 本轮没有使用 localStorage、文件、数据库或后端保存草稿。刷新/关页或浏览器未展示原生警告仍会丢失输入；警告受浏览器策略限制。明确放弃只丢本地输入，不发送保存、撤销或重试，也不能判定此前请求是否已生效。

设备被观察到移除或开始删除时，复用既有 retainMissing/beginRemoval：先停用旧分组编辑器，再复制原始输入为只读分组记录。记录标明打开时上下文，不是已保存配置、备份或身份凭据；仅在本页内存存在，不能自动恢复或应用到同 ID 的设备。干净编辑器也会停用，但不凭空创建脏记录；丢弃旧记录不会解禁旧编辑器或清除新的同 ID 草稿。未决请求不被取消或重试，其结果需另外核查。

异步快照在移除后不能重新启用旧表单；保存结束后只有仍挂载、未停用的原编辑器才可调用原 onSaved。已卸载或停用编辑器的迟到成功/失败不再操作父页面、提示新设备成功或刷新新选择，也不改写已捕获的只读记录。运行中的旧保存仍可能在后端完成，不能把忽略界面回调理解为撤销或取消。
