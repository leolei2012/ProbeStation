# 只读通信统计快照

2026-11-07，基线`f3489c63abfb5ad6c2f5df8c081b841161d19d92`，初始工作区干净，根AGENTS.md/.agents仍不存在。本轮选择通信排障而非继续快照导出、日志或表单关闭保护：原始报文页只展示TX/RX字节，后端早已有超时/错误/耗时统计但前端没有读取。提供有边界的只读统计，不自动解释曲线间断或作测试结论。

审查ModbusDiagnostics计数、缓存复用、PollingEngine.getDeviceDiagnostics与既有GET /api/monitor_objects/:id/diagnostics。getter只查配置与已存在driver，调用isConnected及getDiagnostics；TCP/RTU的isConnected读本地socket/串口状态，不创建driver、不执行getDriver/connect/协议读写、重连或清空。RTU driverKey为串口路径、诊断scope=channel；TCP为设备ID、scope=device。真实设备和API均未访问。

## 用户流程

主站设备“原始报文”页增加“查看通信统计”，默认收起不读取。展开读一次，随后只有用户“重新读取统计”才更新；没有额外定时轮询。重读期间合并在途请求，10秒超时后显示未核实并允许恢复。收起取消本页等待，重开重新读取；设备/连接参数变化换独立reader，旧响应不能覆盖新来源。取消HTTP等待不表示设备采集停止，原始报文页已有帧自动刷新行为不由本入口控制。

展示前端UTC接收时刻、所选设备ID、后台驱动在读取时报告的连接状态、完成成功/失败请求数、其中超时、连续错误、近期错误率、末次/平均/最大请求耗时、TX/RX捕获次数、缓冲记录数和最近成功/错误时间及错误代码/异常码/文本。错误记录即便后来已成功仍显示“可能已恢复”，不把它当当前连续故障；零耗时为0，缺失耗时为—。原后端时间保留原文。错误消息作为React文本显示，换行与长消息不执行HTML。

无已存在driver或后端metrics=null时明确“没有提供诊断计数”，不补零；0个完成请求时不显示0%错误率作为健康结论。后台驱动连接状态不证明特定从站响应、真实物理身份、通信持续正常、样本完整或历史已提交。

RTU统计覆盖共享串口通道的其他设备/从站，醒目标明不能归因当前设备；缓冲总数也可能多于按所选设备筛出的帧列表。TCP按设备ID累计，可能包含此前不同连接配置。诊断缓存跨driver重建/重连复用，不能以编辑配置或重连时刻作为统计起点；原清空诊断或重启可能重置，无持久epoch或自动差分。近期错误率来自最近最多100次已完成读写结果，不是全部生命周期失败占比。耗时亦包括成功和失败请求。

TX/RX记录在底层stream.write/data捕获，可能是TCP/串口字节块，不保证一条对应一个完整协议帧；差值不作为丢包率。请求成功不表示设备业务测试通过。没有新增自动PASS/FAIL、报警策略、阈值、探测、模型发送或错误自动修复。

## 解析与隔离

只接受与当前设备ID、预期device/channel scope及channelKey完全匹配的既有响应；metrics身份再核对TCP设备ID或RTU无单设备ID。缺字段、旧协议无法核实、错来源或坏类型显示未核实，不退化猜测。计数要求非负安全整数，超时/连续错误不能大于错误总数；近期错误率必须0–1有限数，耗时非负有限数，时间若提供必须可解析，错误对象字段保留明确类型。不静默把字符串/NaN/Infinity变成0。合法缺省字段为null供展示，metrics整体NULL与有0计数分别保留。输出白名单与嵌套冻结，服务请求异常只显示固定文本，不回显HTTP/数据库错误原文；业务诊断错误消息仍为用户主动查看的数据。

设备上下文本身无法建立合法来源（例如未知transport）时，组件降级为固定未核实提示，不请求统计、不抛到整个报文页。此边界补充有正式组件SSR回归。

CommunicationSummaryRead复用LatestConfigRead/runRequestWithTimeout，仅发GET且不缓存HTTP响应；本页同步active标识合并读取，取消/新一轮拥有独立序号，旧finalizer不解除新请求锁。失败保留最后合法快照并明确上次结果，加载时旧快照也不标当前。已成功读取本身仍是有限时刻快照，不随其他地方清空计数自动变化，需要手动重读。

客户端连接上下文包含设备ID、transport、串口路径/IP/端口及RTU通信参数，变化重建reader；这只能避免本页旧结果混用，不证明服务端配置读取与诊断读取是事务一致、driver身份认证或物理连接epoch。与同ID/同通道的历史累计记录兼容，不宣称统计从本次连接起算。
