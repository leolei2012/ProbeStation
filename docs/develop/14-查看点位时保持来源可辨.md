# 查看点位时保持来源可辨

状态：已实现，完整离线检查通过；真实浏览器验收未完成。日期：2026-11-06。

## 原因与范围

选点弹窗已显示来源，但选完之后，实时读数、历史曲线图例/悬停读数、表头及采样质量摘要仍只显示别名，跨从站同名同址点位无法辨认。同从站同地址的不同语义定义也存在此问题。

新增共享配置身份标签：

- 名称在完整点表中重名（忽略首尾空格及大小写）时，显示配置从站、FC、地址和点位ID。空别名采用原地址形式 `#地址`。
- 唯一名称保持简洁，完整配置身份在悬停提示中提供。长名称省略时保留完整提示。
- 历史标签按完整点表、实时按完整可选数值点表生成，不随已选项、图例显隐或查询结果改变。
- 来源来自当前配置分组；本地从站模式使用设备从站ID。来源缺失/非法时标记配置来源未知，不默认补1。
- 配置标签不证明历史样本实际来源；现有批次/来源验证状态、数据解码、告警和导出契约保持不变。

这次不启动主应用、不打开真实数据库、不部署运行实例。
