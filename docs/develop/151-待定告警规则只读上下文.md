# 待定告警规则的本页只读上下文

## 机会与取舍

现有命中告警已经显示配置来源、采样时间、批次标记并可跳历史；本轮不重复。待定规则此前只有数量，必须另开配置编辑器逐个找点。新增“查看待定规则”，直接核对本页未取得判定值的规则及点位，不打开编辑器、不读写设备。

其他候选是新增告警事件时间线、自动诊断断线原因。当前页数据不是事件库，也无法证明根因或持续时间，因此本轮不实施这两项。

## 使用与数据边界

实时设备页告警区域点击“查看待定规则”。每页最多20条，支持翻页，不截断总列表；显示规则/点位编号、别名、分组、配置从站、FC、地址、数据类型及原始值条件。`id:编号` 可用于现有实时表搜索。

待定集合直接复用 AlarmPanel 当前已有的来源/质量/批次/时效判定，不另查缓存、不改变告警策略。条件比较类型解码后的原始值，未应用倍率或偏移。主站按分组从站，现有从站模式按设备从站；来源无效显示问号，不猜测。设备/组启停和组错误仅是已有页面标记，不是根因。错误详情、地址端点、消息正文及批次标识不投影到此清单。

配置或规则未核实、正在刷新规则时隐藏保留明细，沿用现有读取状态说明。空列表只表示本次载入规则无待定项，不表示无告警或设备恢复。不提供触发时间、持续时长、真实事件或自动 PASS/FAIL。

界面代码手动展开后按需加载，关闭不挂载；失败明确提示，可仅重试界面代码。共享加载器只缓存代码，不缓存规则、观测或设备配置，迟到代码使用当时最新 props。没有新增 API、轮询、写入、自动重试或外部依赖。
