# 捕获异常标记语义与截断报文回归

## 已核实语义

异常筛选仅读取快照的布尔 `isException` 标记，既不重新解析hex，也不根据异常码、方向或缺失记录推测故障。现有捕获器按TCP字节偏移7/RTU偏移1的高位生成该标记，按后一个字节记录异常码；这是字节块解释，未验证完整帧、长度头、CRC或物理来源。TX上有标记也保留，不能改称“已验证异常响应”。空输入不生成捕获；截断到功能码之前未标记，截断到带高位功能码但缺异常码时仍保留标记。以上是既有行为，本轮没有修改捕获器或解析器。

模拟复现：TCP八字节或RTU两字节的标记捕获没有异常码，旧列表显示 `(err undefined)`。本轮仅将缺失码显示为 `(err ?)`；原始字段仍为undefined，实际码0、255等原样显示，不补码、不丢记录、不把未知字节映射为故障名称。

响应结构解析失败时，整份新快照被拒绝，不能把其合法前缀当作本次成功；已有快照保留并明确未核实，首次失败则不冒充空列表。来源变化不能继承旧快照或筛选，旧来源内容返回新读取器时被拒绝。用户可切回全部查看原始顺序，异常筛选没有匹配不代表没有通信错误。
