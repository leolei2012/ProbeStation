# 实时曲线重合点与悬浮组合验证

基于b9fbcbd干净工作区；未发现AGENTS.md或.agents目录。只使用模拟缓存、真实采样/绘图表达式和Node SSR，不连接设备、数据服务或真实数据库。

## 新复现与最小修复

不同响应批次可以有相同毫秒时间戳。用实际sampleCurve生成两次相同时间、相同零值，缓冲确实保留两个点，读数也为0；但折线长度为零，旧孤立点函数因存在相邻有效点而返回空数组，仍没有可见标记。新增回归在旧实现因期望一个标记、实际为空而失败。

标记判定现按原null/时间阈值划分的连通段处理：整段若都处于同一时间和值坐标，补一个标记；只要段内有不同坐标，保留原折线，不额外加点。重复点不被从采样记录去除，也不改变批次、来源、质量、时效或数值换算。绘图表达式、半径、聚合路径与阈值全部保持，不修改App或服务端。

纯函数补充完全重合零值、重合后延伸成线、同时间不同值的竖线、null两侧重复点和超阈值两段重复点，原输入不变。2400个完全重合零点只产生一个标记，不叠加2400个圆。

## 悬浮与来源组合

通过实际liveReadings表达式分别悬浮到首样本前、有效零值处、质量异常前、null处、缺口内和恢复点：零值显示0且保留对应采样坐标，未知处为横杠和空悬浮标记，不跨null填值。过期位置为未知，来源切换后旧轨迹和旧悬浮值一起隐藏。原单点、冻结/继续、低质量相邻、缺数/过期、多字和清空不重播回归保持。

这是模拟曲线缓存和表达式执行，不模拟实际指针、浏览器事件调度或实机连通性；断段仍不等同某种故障。
