# 分组与默认点位创建事务

## 复现与范围

基于干净的`51ad7f22675112b6ebf58fbff2939833f60e7010`，检查相邻创建流程发现：旧REST先createGroup并通知，再循环createRegister；第二个点位失败时HTTP500，但组和首个点位已经保存，前面通知也已发出。用户可能按“失败”重试，留下额外部分分组。

新回归用真实内存SQLite触发器在第二个默认点位INSERT时RAISE(ABORT)，执行从生产源码提取的实际POST。旧行为下组数2而预期1（只应留原组），断言失败；未运行主应用、真实DB或采集器。本轮只收拢REST创建路径，不扩展导出/Workspace，不改变其他编辑策略。

## 接入与结果契约

- 新增并实际使用ConfigStore.createGroupWithRegisters，参数及默认点位算法沿用旧POST；原createGroup仍仅创建组，避免给导入/备份调用额外补点。
- 明确拒绝嵌套批量操作；具名启用状态仍在BEGIN之前校验，保留77号语义。BEGIN IMMEDIATE放在本操作try外，失败不会ROLLBACK调用者已持有的事务。
- 自己持有事务期间通过现有restoring标志暂缓group/register通知；组和全部默认int16点位完成后COMMIT。正常点位/提交错误尝试ROLLBACK，成功回滚时原图完整不变、不通知，允许用户核对后明确重新创建。回滚本身失败抛AggregateError，结果待核实，不能称已恢复。
- 成功提交后才发group→各register，沿用原事件类型、ID及顺序，每项只尝试一次。同步通知回调抛错时继续尝试其余原事件，汇总一条“已创建但通知失败，勿重复创建”警告；不把它当作需要重新建组的HTTP500，也不在提交后尝试回滚。
- 响应保留原分组字段，追加warnings数组（正常为空），不改成嵌套对象。原省略/0/1启用状态、模式/Slave ID、FC、地址/数量、默认int16和无别名保持；老客户端可继续读原字段。
- 前端groupCreateWarnings接受有效旧GroupRecord没有warnings时为空，验证新warnings并复制冻结；非法成功响应标为结果待核实。GroupModal把警告传给现有onSaved，沿用App关闭/刷新/通知提示。未知5xx/网络创建错误保留输入并提示核对、勿重复创建；已知4xx仍展示原拒绝原因，编辑分支不改。

没有schema/真实库迁移，不持有事务跨网络await，也没有自动创建重试。通知完成不等于所有异步消费者或硬件已确认；只处理本地同步回调可观察到的错误。

## 可控回归

新增显式白名单test-group-create-atomic：实际POST→真实`:memory:`ConfigStore，不导入API bootstrap/poller/驱动，不listen。

- SQLite触发器使第二点失败：整图回滚，旧设备/组/点/告警保留，零部分通知；删除测试触发器后显式再建得到完整图。
- 首个及全部通知观察到完整新图，正常保留group/register原顺序；同步通知全部失败仍HTTP200，完整组/点存在、只一条警告、每事件尝试一次。
- COMMIT故障回滚后可恢复；已有调用者事务BEGIN失败不被回滚；restoring中拒绝嵌套；非法启用参数不进入BEGIN；ROLLBACK未知不返回成功、不发事件。未知事务仅由测试清理自己的内存连接，不推断真实库已恢复。
- 原primitive创建不自动补点；有效旧无warnings响应兼容，异常id/响应/warnings不当成功。

更新上一轮实际GroupModal事件→实际POST→内存库回归，继续覆盖停用创建/原参数默认和非法状态；新增真实通知失败的warnings传给onSaved，以及5xx未知/4xx拒绝时不调用onSaved。其确定性hook驱动不是真实React DOM，不能代替浏览器交互/布局验收。

## 边界与验证

本轮没有实现跨请求幂等：传输丢失、提交或回滚结果不明时仍需核对，不能自动重试或断言没有创建。人工忽略提示重复提交、旧后端/旧客户端及其他仍用primitive自行补点的调用方不获得本REST事务保证。未统一旧创建接口其他输入校验，不新增硬件行为策略。

本轮实际执行`npm run check`退出0：前后端类型检查、构建/按需依赖边界检查及98组安全回归全部通过；另单独执行创建事务/启用状态、旧分组编辑及配置备份回归通过。临时库使用工作区`.npm-cache/probe-test-temp`隔离，没有读取或迁移真实库。首屏JS为491511字节（gzip162902），较本轮基线增加661字节（gzip125），仍在既有预算内；包体结果不代表浏览器加载耗时。仅mock/内存或明确隔离临时库，没有第三方通信或仪器操作。

UI结构未新增，复用原保存/告警提示；浏览器原生行为和实机未验收，遵守既有浏览器限制，不重试受限路径。未推送、部署或重启采集；在用实例版本未核验。
