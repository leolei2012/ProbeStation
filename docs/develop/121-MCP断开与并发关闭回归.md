## 复现与最小修复

产品代码仅增加一行：新会话await connect完成后，若req.aborted或res.destroyed，直接返回。已有finally关闭尚未取得session ID的transport，使这一已观测断开的窗口不再进入SDK初始化。所有权与幂等关闭继续复用120号实现；这不是整个初始化期间的网络存活保证。

保护仅作用于新会话初始化。已接收工具任务仍由原track等待，断开不代表取消，不自动重试。已初始化会话中的单个HTTP请求流断开，也不因此删除整个逻辑会话或破坏后续重用。工具定义、schema、处理函数、响应格式、默认端口和采集行为均未改变。
