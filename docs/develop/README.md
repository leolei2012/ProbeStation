# 开发文档区（Develop Docs）

> 本文件夹由**开发（AI）**维护，记录 ProbeStation 的**代码变更**，供测试/接手者快速了解「改了什么、为什么、怎么验证、有什么坑」。
> 维护边界：只记录实现变更；产品需求见 `docs/product/`，工程现状（as-built）见 `docs/03-开发与接手指南.md`，测试结论见 `docs/test/`。

## 命名与更新约定

- 命名沿用 `docs/` 风格：`两位序号 + 中文主题.md`。
- 每份文档头部带「状态 + 日期」。
- **每次改代码后**，在本文件夹更新对应条目（新增功能 / 修复 bug / 改动数据模型），并在「验证方式」里补冒烟测试命令，方便测试的人复现。
- 引用工程事实（端口、插件、表名）以源码为准，不臆造。
