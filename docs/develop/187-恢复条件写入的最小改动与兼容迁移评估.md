# 恢复条件写入的最小改动与兼容迁移评估

基于a9e2482。本轮只整理可实施设计并重跑已有隔离证据，**不增加实验代码、不迁移库、不启用生产写入**。新界面继续默认阻止；183/184号模型的限制不因本文消失。

## 目标和不能承诺的事

目标是本应用的一次操作始终绑定用户确认的配置来源、编码字和运行时拥有者：要么在受控接纳点拒绝，要么仅交给该预期连接/内存实例，不能等待后换成后台新目标。配置必须在最后受控提交点仍满足条件；接纳后变更不能追溯撤销已提交的字节。

线性化点应明确为受控驱动向底层提交本操作的时刻，不是设备执行、物理线路发出的准确时刻或数据库COMMIT。进入底层后，丢回执、取消、关闭、进程崩溃均可能留下未知结果。Modbus地址/IP/串口名称不是物理设备认证；不保证外部控制器不会改设备值。

## 已核实的入口与最小接入位置

| 入口/资源 | 现状证据 | 恢复前所需最小处理 |

| REST数值写 | api/register-write.ts按ID读取当前点/组，再调用poller.write | 新增独立、强校验的条件入口/版本化契约；旧路由不偷偷忽略expected。准备与执行绑定同一计划，执行不得改值/来源。 |

| 从站接收外部FC05/06/15/16 | slave/protocol.ts的SlaveMemory.respond及RTU session直接更新本机内存 | 保持协议及范围校验；外部主站不是GUI确认调用方。与本机管理员写共享内存实例/生命周期约束，不给Modbus帧强加应用票据，也不承诺值比较交换。 |
| 助手、录制、日志/历史写 | 此次静态搜索没有助手直达硬件写；助手是读取/配置提案，录制和store.write是数据存储 | 不把存储write误列为硬件命令；配置提案/导入等仍需参与配置代际维护。保留源码核查范围，不能把文本搜索当全仓库形式化证明。 |

不改旧外部契约不等于旧内部I/O可绕过新通道：若旧调用、OTA或其他插件能在同一连接/串口另建队列，新条件入口必须失败安全。第一阶段无需开放全部行，但必须知道并隔离它们。

## 最小配置代际设计

建议先选保守的全局配置代际，而非一开始做复杂的点级依赖图。逻辑身份至少包含“当前配置连接/运行实例作用域＋不可复用的已提交配置版本＋当前通道/内存实例代际”。组快照revision是内容哈希；录制scope/source guard也不覆盖全部点/组/设备字段，二者不能直接冒充此版本。

| 要素 | 最小要求及代价 |
|---|---|
| 一致计划快照 | 在同一受控事务中读取设备、组、点及权威版本；关联ID、角色、从站、area/FC、起始地址、宽度/字序、类型、请求方法、最终字全部冻结。MCP工程值还绑定factor/offset；别名等可保守纳入版本，但当前采样值、日志和统计不能让每次采样都使确认失效。 |
| 代际维护 | 所有影响图的create/update/delete、缩容、批量导入/恢复、条件与旧REST/MCP配置路径、助手提案都要在同一SQL事务内推进代际；回滚不公布已提交版本，通知失败不撤回版本。仅靠config/changed计数不足以处理未观察ABA。 |
| 外部写者 | 若允许别的连接直接SQL修改，须验证数据库层版本维护（例如经过审计的触发器）与短提交互斥；只改ConfigStore入口无法覆盖它。若仅支持单控制进程/受控写者，必须明确支持边界，未知时不开放能力。不能通过扫描或猜测证明无外部写者。 |
| 生命周期 | 启动、重开、恢复/替换库、连接隔离和运行时重连/关闭都失效旧票据。即使恢复旧版本、ID重用或A→B→A，也不能复用旧确认；内容相同不等于同一代际。 |
| 表达及迁移 | 持久版本需要选择可无损读取的整数/文本表示，达到上限即关闭能力而非回绕；备份/还原、旧版回退及多连接必须有合成库测试。本文未定DDL、未加列/触发器、未读取真实库。全局代际会产生保守冲突，这是简单性的明确代价。 |

如果最终检查与原生提交间还允许其他配置写者提交，就没有原子条件保护。可评估短的配置互斥/数据库写许可覆盖“最终读取与同步接纳”，但绝不跨网络连接、队列或响应await持有SQLite事务。接纳后提交/释放发生异常须按已接纳处理，不能把SQL回滚说成硬件回滚。这个原生提交边界当前尚未证明，仍是开放问题。

## 驱动队列所需的最小改动

1. 为条件操作定义不可变计划及拥有者；共享范围按实际资源确定。TCP不能只凭设备ID排除相同端点别名，RTU至少按串口及连接配置统一控制；未知别名/共享关系不能靠DNS探测或端口握手猜测。
2. 让排队发生在应用可撤销、可计数的通道队列中。等待期间可以失效；许可生效、连接完成后都复核版本。getDriver不得刷新成另一个目标；驱动必须返回实际绑定及代际。
3. 在公开稳定、按操作可识别的最终提交边界核对计划、通道拥有者和配置版本。184号仅在模拟Duplex的_write证明此性质；不能上线覆盖socket.write或patch jsmodbus私有队列。相同RTU字节无法识别不同操作，不能从帧内容反推ticket。
4. 许可覆盖所有相关应用内读写/原始流生命周期，避免SDK已有排队工作在许可释放后继续发送。保持至回执有串行化好处，但也有超时、长占用与吞吐代价；先证明准确的接纳/完成状态，再决定释放点，不以Promise.race当取消。
5. 统一锁顺序并拒绝重入。配置临界区不等待通道，通道拥有者不在响应链里反向等待被编辑者占用的配置锁；故障清理只释放自己持有的资源。关闭共享端口不能作为选择性撤销某一操作的默认手段。

上述最小改动涉及core契约、config版本/快照、poller通道、modbus提交适配、slave生命周期、OTA/raw拥有者、API/MCP与前端确认。只新增一个expected字段或前端重读不能替代其中任何必需边界。

## 兼容迁移与失败语义

| 阶段 | 可交付内容与停止条件 |
|---|---|
| 0：当前默认 | 新界面继续阻止；旧接口继续原行为，明确风险。不启用模型路由或实验sink。 |
| 1：权威版本与资源覆盖 | 仅合成库、模拟传输证明迁移/回滚、ABA、ID复用、外部写者边界及所有应用内共享入口；未满足者能力保持unsupported，不接入新界面发送。 |
| 2：窄能力端到端 | 优先评估一个TCP单连接、明确点ID/从站、已有命令子集；准备/执行采用独立强契约，版本不识别、旧后台、空能力、资源忙或运行时未知均阻止。具体首批FC/类型及支持写者范围待确认，不能把它当作本轮已批准的生产范围。 |
| 3：模拟验收后才接UI | 服务端权威计划回显源、原始/工程值模式、最终字和支持范围；用户确认后只执行该计划。操作ID/回执须绑定请求，旧响应、普通503、代理改写和丢响应不能推断未执行。旧前端＋新后台、反向组合及同版本均要测试；绝不自动降级到旧POST。 |
| 4：旧接口迁移 | 新REST/MCP为独立版本/工具名；旧结构、返回及默认行为先保持。是否废弃、禁用或限制旧无条件调用是单独产品决定，不能静默破坏兼容。保留旧调用时，不宣称全系统所有写入已受保护。 |

计划票据还需要授权主体/请求、值和方法绑定、期限、容量、单次接纳、清理及进程崩溃策略；不把UUID当鉴权。准备只读，不发送；过期或发送前冲突要求重新确认。已交底层但无回执统一保守为未知，不自动重试、不伪称幂等。结果查询如需跨重启，持久操作状态也不能与硬件执行组成数据库原子事务，这是另一项明确成本，不能未经评估增加存储基础设施。

## 关键不变量与本轮证据

重用现有审计，不增加未接入原型：183号64场景覆盖确认/队列/连接/发送门、代际/ABA及票据/未知结果；184号25场景使用已安装SDK与内存流覆盖内部队列、取消、RTU共享、锁循环等。负对照通过表示缺口被复现，**不是生产安全通过**。新界面专项继续验证零UI发送、输入与语义关联、重复/迟到入口及在途旧请求不被取消。

候选v108隔离重跑：audit-guarded-write --mock的64个场景、audit-write-send-boundary --mock的25个实际SDK/内存流场景，以及test-register-write-value的数值校验/实际旧路由/8种UI组合/在途旧请求回归均退出0。ABA、内部队列和旧接口SOURCE GAP仍按预期复现，不能视为来源保护通过。证据日志为write-recovery-design-model、write-recovery-design-sdk、write-recovery-design-ui；本轮没有新建原型、改变这些测试或扩大支持范围。

本轮仅新增本文，不改任何源码、测试、依赖或配置；全部755个候选文件逐blob核对，其余文件与a9e2482一致，在用dist六文件路径/长度/哈希不变。没有重跑全量144套、类型检查或Vite构建，不引用历史结果代替本轮验证；没有浏览器或硬件验收。全量源码核对后仅补录本文；无未解决测试失败或工具审批阻塞，生产恢复条件仍未满足。

## 开放问题及硬件验收需求

开放决策：单控制进程还是多写者；全局版本的保守冲突是否可接受；受支持驱动提交能力的公开实现方式；首批传输/FC/类型；本地与全局从站内存是否单独上线；OTA/重复端点别名协调；旧REST/MCP退役策略；回执与跨重启操作查询的成本。

真实库迁移、真实驱动/内核缓冲和实际硬件写入均未验收。未来需要另外授权的专用可写测试从站/测试地址、允许值域及停止条件，不能使用正在运行的现场设备默认代替。需用隔离抓帧核对端点、unit、area/FC、地址、宽度和值，覆盖排队时配置变更、ABA、重连、丢回执、异常关闭、并发旧调用及RTU/OTA互斥；发送前拒绝必须在线路证据上成立，发送后的未知结果不得自动重试。抓帧仍不构成物理身份认证。

在这些条件未满足前保持新界面阻止，不为了验证而操作真实仪器、降低校验、覆盖在用构建或重启采集。本轮无推送、部署、新依赖、实际模型服务或真实数据操作。
