# 历史引用跳转不重复应用

状态：已实现，最终完整离线检查通过；浏览器交互验收未完成。日期：2026-11-06。

## 已验证的问题

原HistoryView跳转effect依赖点表数组。通过助手历史引用进入页面后，配置通知/编辑刷新会生成新数组，effect重复设置引用中的日期、点位、页码和曲线模式，覆盖用户后续分析。原导航token还使用Date.now，极快连续点击可能共用同一毫秒。

纯状态回归中，同一目标已应用后仅增加点位数组，旧逻辑仍输出一次范围重置，先失败再修复。

## 当前行为

- 同一历史视图挂载期间，带时间范围的同一导航意图只应用一次日期与曲线模式；后台点表刷新不会重放。客户端导航使用递增序号，重复点击同一引用也能发起新定位。
- 点表尚未加载时记录待定位ID；完整配置快照就绪后仅补点位选择，不再次改日期/模式。用户可先修改日期或切为表格；手动选择点位会撤销待定位。
- 就绪以当前设备已加载的配置快照判断，空点表也能正确结束等待。当前已加载点表缺少目标ID时提示刷新配置后重新点击引用或手选，不按别名/地址猜测，也不偷偷改选其他点位。
- 等待/缺失/无效目标期间清空目标选择，沿用空选择不查询的保护；一般不指定点位的范围引用保留当前选择。只检查合法设备归属、时间先后/有效性及正安全整数点位ID。
- 显式新跳转重置曲线视窗并重新查询，即使范围相同、前次失败或取消也能重试定位；手动点击设备清除旧跳转目标，防止后来进入该设备时复活旧引用。

本轮不修改历史接口、点位定义、采样、告警或模型服务；不改变现有秒级日期输入格式。没有时间范围的目标沿用原先仅打开页面的行为。

## 限制

实际浏览器点击引用、等待点表、手选、提示、重复定位/缩放及窄屏未验收；此前浏览器连接受限，本轮不重试受限原生Edge或扩大权限。纯动作模拟不等于DOM交互。

缺失判断基于浏览器当前已加载配置，不证明服务端点位已删除。缺失后需要新一次明确跳转或手动选择，不在后续无关更新中自动重试。HistoryView卸载/重进页面仍会重新初始化，本轮未新增跨页面/重启的分析状态保存。未部署、重启采集服务或读取/修改真实数据。
