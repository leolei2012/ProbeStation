# 冻结快照样本年龄预览

## 选取依据与改进

实时筛选、观察清单、冻结/JSON下载和前后对照已有能力，本轮不重复这些功能。单份冻结预览原有点位、原始/物理显示值及状态四列，虽然模型已保存每点 `health.ageSeconds`，用户仍须下载JSON才能知道“旧值”旧了多久。专项在既有界面上先复现年龄信息缺失，再增加显示。

冻结预览增加“冻结时年龄（秒）”列，直接显示冻结时保存的 `health.ageSeconds`，不计算当前年龄、不更新冻结值。0是合法年龄；null、负值或非有限值显示“未知”。部分缺字且存在原字时标注“仅已有字”，全部缺字不暗示有样本。

说明明确：年龄按最早已知字相对状态依据时间计算，冻结后不递增；缺字、质量、批次和来源仍须核对。0秒也可以同时显示旧值/异常或批次混杂，年龄不代表质量正常、来源已验证或PASS。沿用 `pointHealth` / `sampleAgeSeconds` 既有时间容忍和取最早已知字规则，不改阈值或未来时间处理。

只改预览组件，JSON格式/内容、冻结范围、分页、下载及采集行为不变，不增加请求、定时器、依赖、数据库字段或写入入口。表格继续使用已有可聚焦横向滚动容器；真实窄屏视觉尚未验收。
