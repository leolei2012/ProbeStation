# 点位枚举草稿与未编辑保留

2026-11-06，基线`df94654`。本轮只改本地代码、合成数据及内存库测试，不启动或重启服务、不读写真实配置、不接触设备、不部署或推送。

## 问题与契约

原编辑器把无法解析的枚举JSON变为空行，所有保存都从行重建枚举，空行发送`enumJson:null`。因此只修改单位也可能清空原文；合法旧映射的补零键、标签空白会被规范化，非整数键、空标签或规范化后冲突也会阻止无关字段保存。

配置备份/语义导入允许字符串映射，未限制键为整数或条数为200；配置库更新支持省略字段。保留现有服务端契约：未编辑枚举时请求中真正省略`enumJson`，不是发`undefined`、原文快照或`null`。服务端因此保留当前值，包括打开编辑器后别人修改的枚举；App原有读回核对只检查本次发送字段，继续适用。

## 编辑行为

- 原文与行草稿分开保存。字符串映射保留原键/标签；无法解析、数组、非字符串值等作为无法逐行读取的原文，明确说明不会自动清空或转换，其他字段仍能保存。
- 原文可只读展开，标题标明是本次打开时快照，不冒充当前服务端值。React转义文本；原文不作为HTML渲染。
- 修改后又精确还原到打开时各行，或添加再删除新行，恢复为不发送枚举。空对象原文也不自动改为`null`。行ID不重复使用。
- 对无法逐行读取的原文，必须点击明确替换入口才开始新映射；先生成一条必填空行，避免直接误清空。清空入口明确提示保存后生效，撤销只恢复枚举草稿，不影响单位等草稿。
- 明确编辑后仍校验整份映射：整数键规范化、标签首尾去空白、拒绝重复键/空标签。错误附行位置并跳到所在页；重复保存同一错误也会重新定位。显式清空发送`null`。原值本就为空时，清空不发送字段，避免删除未看到的并发新增枚举。
- 每页20行，底层保留全部条目；不沿用缺少存储契约依据的200条添加限制。添加跳到新行页，保存整份草稿，未显示页不会丢失。

未改变采样、寄存器写入、枚举显示解码、倍率、告警或点表格式。原全量DTO解析函数保留原有行为，只有编辑器采用新的部分更新构造器。

## 纯模拟手测

在项目目录执行`npm run preview:settings`，手动打开`output/playwright/point-settings-preview.html`。正式编辑器配合合成配置，仅更新页面内存；资源内联且CSP禁止网络，不启动服务、不读写配置库。关闭页面停止并丢弃模拟内容。

1. 选择“JSON损坏”“数组”“非字符串标签”：查看原文，只改单位保存，检查“最近发送字段”没有`enumJson`且内存枚举原文保留；取消后重开也不产生保存。
2. 选择补零/空白或规范化重复键映射：不改枚举可保存其他字段且原文不变；明确编辑后应用原整数键/标签校验；撤销枚举草稿后其他草稿保留。
3. 异常原文明确替换：空白行保存被拒绝，填入整数及标签后保存；单独测试清空、撤销、取消和失败一次后重试，确认失败保留全部草稿。
4. 选择500条映射：翻到末页编辑并保存，确认全部500条保留；制造后页空标签，回首页保存，检查自动跳到错误页；手动离开错误页再保存，应再次定位。添加/删除/撤销后核对页码。
5. 打开前勾选模拟并发更新：不编辑枚举，保存后应保留模拟的新枚举；明确编辑/清空会覆盖它，体现当前并发边界。该模拟不连接后端。
6. 缩至360px核对按钮折行、原文滚动、行输入与错误提示，检查键盘操作及繁忙时禁用。模拟页不等于真实后端写操作验收。
