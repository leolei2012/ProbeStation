# 编辑器完整关闭回焦

本轮从83830d6的干净工作树开始，仅修复已模拟复现的设备/点位编辑器完整关闭后焦点落回页面空处的问题。未推送、部署、重启采集、连接设备或读取真实数据库；在用dist不覆盖。不扩展全局弹窗栈。

## 证据与最小行为

实际入口是App的新增设备窗口、DeviceView编辑设备窗口及LiveTable点位设置。onClose只清除显示状态；设备保存成功由父层隐藏窗口，点位保存成功由编辑器触发onClose。原代码仅处理“继续编辑”的窗口内回焦，完整卸载无清理回焦。新增实际编辑器回调测试在修改前以“point/clean: complete close must restore the opening button”失败；只用有限焦点模型，没有据此宣称真实浏览器复现。

两个编辑器在首个render捕获当前activeElement，先于本窗口autoFocus；SSR没有document时为null。局部useDraftDialogFocus复用原保存中/确认/继续编辑逻辑及稳定ref，并为真实卸载绑定清理。清理仅当下列条件全部满足时聚焦原对象：

- 旧表单已从文档移除；仍连接时的effect清理（含StrictMode重演）不回焦。
- 同一文档的当前activeElement是body，且没有其他aria-modal=true的元素。用户、新视图或另一个窗口已拥有焦点时不抢回。
- 原对象仍连接、仍属于同一文档且不匹配:disabled；包含fieldset继承禁用。原对象消失或不可用时不按设备ID、点位ID或同名按钮寻找替代者。

无延时回调、动态导入、全局监听、持久化或配置写入。清理不触发点击、保存、撤销、请求取消或重试。父层在onSave返回前卸载的设备窗口沿用原契约，不新增子窗口onClose。

## 未覆盖与取舍

- 没有真实浏览器、键盘或读屏验收，尤其需检查React被动effect清理顺序、StrictMode、原生autoFocus/点击焦点、可见焦点及滚动。
- 捕获的是打开render时activeElement，不保证程序打开、触屏或不聚焦点击的平台上一定是实际打开按钮；没有原对象时不猜测。
- 目标可聚焦性仅核对连接、同文档及原生禁用，未建立完整隐藏、inert、CSS或shadow-DOM可聚焦引擎；浏览器可能拒绝focus。没有自动聚焦任意页面标题或body。
- 另一模态窗口检测只做保守避让，不是全局栈、背景inert或多窗口所有权证明；交错卸载的真实浏览器行为仍需验收。
- 本轮不改变原生beforeunload、草稿留存或保存结果未知语义，不承诺请求取消或输入持久恢复。
