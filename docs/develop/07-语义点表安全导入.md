# 语义点表安全导入

2026-11-06，基线07b2e0c。只使用内存配置库、合成表格与请求注入验证，没有导入用户配置、操作硬件、启动或更新运行服务。

## 问题与选择

旧ConfigStore.importPoints按FC/地址find首项，同设备多从站同址时会静默改错来源。内存回归先失败：预期updated=0，实际1。API还给省略的dtype/unit/enum补默认值；智能CSV总是生成所有语义列，导致只改别名也可能重置原类型、单位、枚举和换算参数。MCP的unit/enum也有同类默认问题。

现在JSON、CSV、XLSX语义导入和MCP共用选择与字段规则。不是全量点表XLSX替换、MBP/MBS追加或JSON备份恢复；这些独立入口未改。

## 精确选点

`POST /api/monitor_objects/:id/points/import`路径不变，JSON数组支持：

```json
[{"area":"holding-register","address":0,"slave_id":2,"alias":"电流"}]
```

也可提供register_id精确选择已有点位，同源同址存在多个语义定义时必须用ID。设备、area/address和所有显式选择条件需同时匹配；不匹配或歧义的行跳过，返回候选，不回退首项。来源按当前分组绑定，本地slave模式按设备自身编号。旧无选择器用法在匹配唯一时仍可用。选择器只接受数值整数：slave_id为0–255，register_id为正安全整数；这是共享元数据选择范围，不扩大现有设备请求协议范围。

CSV和语义XLSX（base64、首工作表）可使用slave_id、Slave Address、Unit ID、从站ID/从站地址，以及register_id、Register ID、Point ID、点位ID。普通ID列不猜为点位ID。示例：

```csv
slave_id,address,alias
2,0,电流
```

缺少选择列允许唯一匹配，非空非法选择值直接报解析错误并跳过，不降级为无选择。重复地址/数据区/来源/点位ID列拒绝整表，以免取错列。地址启发式沿用0x、40001等既有规则；请核对parse.columns/parse.errors，不能把解析成功当成设备地址已确认。

## 字段保留

| 输入 | 行为 |
|---|---|
| JSON省略字段，CSV/XLSX没有该列 | 保留已有字段 |
| JSON unit/enum显式null | 清除该字段 |
| JSON alias=null | 沿用旧行为：不更新别名；空字符串可清空 |
| CSV/XLSX有列但单元格空 | 沿用旧行为：unit/enum清除、factor/offset为0、dtype默认int16、空alias不更新；空格也视为空 |
| 非法类型/非有限倍率或偏移/非法枚举映射 | 跳过该行，不转换字符串数值或写半行 |

CSV保留旧类型/地址启发式，同时规范dtype（包括32/64位、q31及LE）直接识别；显式未知类型/数据区跳过。JSON使用编解码器已有dtype（包括旧_LE兼容拼写），不猜新类型。显式dtype的完整字宽须落在所属组和0–65535地址范围内，不扩组。quantity是独立元数据，不改写，也不拿它重算宽度。

ConfigStore底层接收camelCase functionCode/address/slaveId/registerId等；REST和MCP接收area及snake_case，REST也兼容camelCase。冲突的snake/camel选择器或dtype在写入前400。只接受FC01–04对应的语义读取区。语义更新不会新建或重挂设备、组、点位，也不更改告警、数量元数据或历史数据。

## 报告与事务

保留updated/skipped/errors，增量返回details和warnings。details含规范化点数组的0-based row、code、error及可用candidates；CSV/XLSX还返回parse，解析行号与表头/跳过行有关，不能把details索引当原文件行号。errors仍是可读字符串并附候选摘要，兼容读取原报告的调用方；尚未新增候选选择UI。

沿用逐行校验/跳过策略：无效行不阻止其他有效行，有效行先统一计划，再在一个SQLite事务中写入。重复的明确目标仍按输入顺序执行，最后一行覆盖前行，updated统计有效行数而非不同点位数。无字段的行计skipped但不是错误，空导入不写入或通知。

写入或提交失败回滚，不留下部分语义变更，重试可正常执行。回滚本身失败明确报告结果不确定；不得自动重试。提交后一次config/changed，scope=point-import、id=设备ID；现有消费者监听所有scope，已检查兼容。同步通知失败返回“已提交，勿重复导入”warnings，不能把已提交数据误报成可无条件重试的失败。MCP也保留CSV解析报告；处理后的日志写入失败只增警告，不丢弃导入结果。HTTP异常返回400/404或隐藏内部异常的500。
