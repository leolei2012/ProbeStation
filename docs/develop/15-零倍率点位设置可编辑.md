# 零倍率点位设置可编辑

状态：已实现，完整离线检查通过；浏览器验收未完成。日期：2026-11-06。

## 已验证的问题

点表与备份允许有限倍率0，存储能原样保留；现有 `physicalValue` / `curveValue` 已按“原始值 × 系数 + 偏移”处理0。但是 `PointSettingsEditor` 的保存校验额外拒绝0，用户打开已有零倍率点位，仅修改单位也无法保存。

本轮先将原有草稿校验提取为无副作用函数并保持原判定，用零倍率失败回归确认问题，再仅移除非零限制。原有类型跨度、空/非有限数字、枚举整数/重复/空标签及字段整理行为保留。未改变API、存储、dtype、采样、告警和物理值换算实现；不迁移或修改真实配置。

中英文错误提示现在明确允许0。数值类型的倍率为0时提示有效原始值的物理结果等于偏移，原始采样和告警比较不变。hex/bin格式仍不作物理换算，不显示这条提示。缺失/无效采样不会因为零倍率变成有效常数。

## 纯模拟手测入口

执行 `npm run preview:settings` 后手动打开 `output/playwright/point-settings-preview.html`。复用正式编辑器，初始配置为倍率0/偏移12.5，所有保存仅更新页面内存。资源内联、`connect-src 'none'`，无网络、数据库或硬件；关闭页面即可停止。预览生成器只接受固定 `--settings` 选项，不接受配置/数据库路径；原 `npm run preview:picker` 继续可用。

手测顺序：改单位并保持倍率0保存/重新打开；负倍率；清空数字/重复枚举；取消后不保存；勾选下一次模拟失败，保存失败后保留草稿，直接再次保存恢复；360px窄屏。模拟失败只是组件回调抛错，不代表后端故障或真实持久化测试。
