# 本页暂存查询条件

2026-11-06，基线`599a9b9`。只开发本地工作区，不更新运行实例、连接实机或读取真实数据。

## 选择原因与行为

`DeviceView`离开历史标签会卸载`HistoryView`，再次进入会重建默认时间/模式。排查多个故障窗口时，反复重新输入时间、点位和数值模式不便。本轮增加显式命名的条件暂存，不自动记录浏览过程，也不扩展成样本存档或共享书签。

- 在历史页展开“本页暂存查询”，选择完整区间或当前曲线视窗，输入名称后保存。保存的是绝对整数毫秒、精确点位ID及配置签名、表格/曲线、原始/物理量、输入时区与范围来源。
- 内存由当前设备页持有，跨历史标签卸载/重挂载保留；设备切换、页面刷新、标签关闭或设备页卸载后清空。没有localStorage、文件、数据库、新接口或额外请求。已有点位/数值模式偏好沿用原逻辑。
- 相同名称及完整条件去重；同名不同条件、不同名相同条件允许并存。无固定条数或点位数截断；条件每页5条，定义每页20条并显示总数，可筛出缺失/变化定义。移除只删除内存条件。
- 应用前检查整条条件，成功后取消旧客户端查询、重查历史并从表格第1页或新图开始，重置视窗、图例/Y轴和A/B上下文。即使URL相同也显式重查。暂存视窗作为新的完整查询区间，不恢复嵌套缩放层级。
- 条件可在查询失败、无数据或加载中保存，仍仅表示用户所选条件，不表示结果已查到、有效或可信。配置未就绪时不能保存或恢复；非法区间、空选择、重复/缺失ID拒绝保存。

## 配置变化与身份边界

恢复按设备ID和精确点位ID，不按别名、地址或从站猜映射；所选点位任一缺失或定义变化就阻止整条恢复，所有状态修改仅发生在校验通过后。不会悄悄删掉缺失点位，也不会把旧点表写回当前配置。面板显示缺失/变化计数和可分页的捕获定义。

连接签名只投影已知字段：设备ID、主从模式、传输、IP/端口、串口路径及串口参数，从站模式还包含设备从站ID。严格比较，即使改变暂未使用的连接字段也会要求重新选择；设备名称、启停、轮询/超时不影响条件。主站的来源取点位的当前分组映射，不取设备默认从站号。

点位签名含所属设备/分组、ID、别名、功能码、地址、类型、配置从站及歧义标识、倍率/偏移/单位/枚举/小数位。零倍率保留；无从站身份仍未知，不补为1。同名同址的两个从站是两个ID，不合并。重复ID或不完整定义不能暂存；未选点位增删不影响原条件。

这是客户端配置快照校验，不是后端事务或CAS。后端可能在本次配置读取后变化；相同ID/相同定义的其他工作空间或实例无法从这些元数据识别。应用条件始终查询当前后端现有历史，不保证重现旧结果或其来源。暂存名称/定义不包含采样数据或密钥等任意扩展字段。历史批次、来源、质量、缺口和自动判断仍沿用既有规则；配置相同不等于样本已验证。
