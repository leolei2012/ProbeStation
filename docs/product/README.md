## 当前产品结论（一句话锚点，先看这里）

> **ProbeStation = 给 AI agent 的 Modbus 原始数据通道。** 平台读/写原始寄存器值、忠实执行、不兜底；语义（名称/单位/缩放/枚举）**直接存在寄存器配置里**，读/写时平台自动翻译。

- **核心结论**：平台做数据区/类型/缩放/枚举翻译，不做安全拦截、不做按名寻址。
- **近期开发**：RTU 串口、数据新鲜度、OTA、快采样、数据保留、连续/触发录制、语义翻译（scale/unit/enum，含 Q1.15）均已落地；后续重点是时序降采样。
- **已砍掉**：YAML 语义清单（语义字段已内置到寄存器）、按名寻址、安全护栏、ASCII 模式。

## 三、命名与格式约定

- 命名沿用外层 `docs/` 风格：`两位序号 + 中文主题.md`。
- 每份文档头部带「状态 + 日期」，结论类文档标注是否定稿。
- 引用工程事实（端口、插件、表名）时，以 `docs/03-开发与接手指南.md` 与源码为准，不臆造。
