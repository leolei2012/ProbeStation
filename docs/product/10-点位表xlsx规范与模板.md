# 点位表 XLSX：格式与填写说明

> 版本：v2 · 2026-10-08。使用新版模板，不再支持旧版点位表。

点位表用于导出、编辑并导回一台设备的点位及告警配置。文件按分组组织，列宽、自动换行、冻结表头和筛选便于人工查看。

## 工作簿结构

- **设备信息**：连接参数供参考，导入不修改设备连接。
- **每个分组一页**：点位类型、单位、换算、枚举、显示精度和告警数量。
- **告警规则**：每条告警独占一行，同一点位可以有多条规则。无告警时保留表头。

设备信息和告警规则是保留页名，不能作为点位页名。导出同名分组时，点位页名加「分组_」前缀；实际分组名仍保存在第一行。

## 点位页

第一行：`分组 | 分组名`。第二行：`从站 | 值 | 功能码 | 值 | 起始地址 | 值 | 数量 | 值`。第三行空白，第四行列头，第五行开始每行一点位。前十列按以下固定顺序填写，不要移动列。

| 列 | 名称 | 填写示例与说明 |
|---|---|---|
| A | 别名 | 温度 |
| B | 数据类型 | int16、uint16、float32 等 |
| C | 单位 | ℃、V、rpm；可留空 |
| D | 系数 | 0.1；物理值 = 原始值 × 系数 + 偏移 |
| E | 偏移 | 0 |
| F | 枚举 | `0=关闭;1=开启`；可留空 |
| G | 功能码 | 3；该点的 Modbus 功能码 |
| H | 起始地址 | 0；十进制地址 |
| I | 数量 | 1；该点字宽 |
| J | 小数位数 | 0–8，留空自动；只影响显示 |
| K | 告警数量 | 导出时计算，仅供阅读，修改此列不创建或删除告警 |

枚举按解码后的整数原始值匹配，不应用系数与偏移。历史物理值按当前配置换算。曲线和采样不因显示小数位数而舍入。

## 告警规则页

第一行为以下固定列头，第二行开始每行一条规则。通过「分组 + 功能码 + 起始地址」对应点位，不使用内部数据库 ID，便于复制到另一台设备。

| 分组 | 功能码 | 起始地址 | 告警条件 | 原始值阈值 | 告警提示 |
|---|---|---|---|---|---|
| SYS | 3 | 0 | >= | 800 | 温度过高 |
| SYS | 3 | 0 | < | 0 | 温度过低 |

- 条件支持 `>`、`>=`、`==`、`<=`、`<`、`!=`，也接受 ≥、≤、=、≠。
- 阈值必须是有限数字，允许负数和小数。比较对象是按点位类型解码后的**原始值**，不应用工程换算或显示舍入。
- 提示可留空，最多 200 个字符。
- 分组名、功能码、地址必须对应一个且唯一的点位；修改点位定位字段时，请同步修改告警规则页。
- 新增一行创建规则，删除一行移除规则。同一点位多条规则直接填写多行，不需要 JSON。
- 导入前检查所有告警行；格式错误或找不到点位时，返回行号错误并保留原有配置。

界面入口：设备「实时数据 → 配置」，点击具体点位的「告警」。触发时顶部显示告警、原始值和物理值标红；恢复后取消标红。数据过期、采集暂停或通信异常时不判断为当前告警。

## 导入与导出

Web：设备「实时数据 → 配置」工具栏的「导入点位」「导出点位」。

- REST：`GET /api/monitor_objects/:id/points/book` 下载；`POST` 同一路径上传 XLSX 二进制。
- MCP：`export_points_xlsx(device_id)` / `import_points_xlsx(device_id, content_b64)`。

导入默认**全量重建目标设备的分组、点位和告警**，会移除文件中没有保留的旧配置。请先导出备份，再编辑并导回。设备连接参数保持不变。新版模板必须保留「告警规则」页，无规则时只留表头。

## 生成模板与验证

```bash
npx tsx scripts/new-pointsheet-template.ts
npx tsx scripts/test-pointsheet.ts
```

模板输出到 `docs/pointsheet-template-example.xlsx`，另附同名 TXT 说明。模板包含两条温度告警示例，正式使用前请按设备原始值量程修改或删除。

图形界面的点位「设置」可编辑单位、系数、偏移、枚举及小数位数；这些配置随点位表一起交换。
