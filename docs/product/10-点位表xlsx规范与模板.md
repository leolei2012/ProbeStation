# 点位表 xlsx：格式规范与模板

> 版本：v1.1 · 2026-10-08
> 主题：ProbeStation 设备「点位表（寄存器点表）」的 xlsx 交换格式。用于**按分组**整本导出点表 / 回导（同一份 xlsx 可再导回，多台设备点位分组相互拷贝最省事）。
> 实现方：`packages/sink`（`exportPointSheet` / `importPointBook`）；端点 `packages/api`；Web 与 MCP 均可调用。

---

## 1. 一句话

把一台设备的点位导成一个 xlsx；**每个寄存器分组 = 一个 sheet**，另外有一个「设备信息」sheet 记录连接参数。文件可原样上传回同一台或另一台设备，重建其点位。

## 2. 为什么是"分组 = sheet"

设备层级是 `设备 → 多个寄存器分组(register_group) → 每个分组读一段连续地址`。分组是轮询、显示的最小组织单位。把**分组作为 sheet**：一眼看清整张点表哪几段地址、每段里有哪些点名/类型，编辑/交接不丢失"归组"这个结构。

## 3. 文件整体布局

```
Workbook:
 ├─ sheet「设备信息」   （记录连接参数，1 行为"字段/值"）
 ├─ sheet <分组名A>     e.g. RO / RW
 ├─ sheet <分组名B>
 └─ ...
```

## 4. 每个「分组」sheet 的固定布局

sheet 名 = 该分组名（非法字符 `\ / : * ? [ ]` 会被替换为下划线且 ≤31 字符；空名退回 `分组<序号>`）。

一个分组 sheet 的行结构（`exportPointSheet` 写出、`importPointBook` 同样解读）：

| 行号 | 内容 |
|---|---|
| 1 | `分组` , `<分组名>` |
| 2 | `从站` , <v> , `功能码` , <v> , `起始地址` , <v> , `数量` , <v> |
| 3 | (空行) |
| 4 | 数据列头：`别名 | 数据类型 | 单位 | 系数 | 偏移 | 枚举 | 功能码 | 起始地址 | 数量 | 小数位数` |
| 5+ | 每个：一点（一行寄存器） |

> 第 5 行起每行一个寄存器。第 7–9 列（功能码/起始地址/数量）是**该点自身**的读属性（正常与分组头一致）；别名/数据类型/单位/系数/偏移/枚举是点的语义，第 10 列控制显示精度。空行（别名、地址、类型都空）会被跳过。

### 4.1 列头（第 4 行）含义

| 列 | 含义 | 示例 |
|---|---|---|
| 别名 | 点位名（描述） | 电源开关 |
| 数据类型 | 解码类型 int16/uint16/int32/float32/hex16… | int16 |
| 单位 | 工程单位 | ℃ / rpm / 空 |
| 系数 | 物理值 = 裸值 × 系数 | 0.1 |
| 偏移 | 物理值 = 裸值 × 系数 + 偏移 | 0 |
| 枚举 | 离散标签，`值=标签;值=标签…` | 0=OFF;1=ON；空 = 连续量 |
| 功能码 | Modbus 功能码（3 读保，4 输入…） | 3 |
| 起始地址 | 寄存器起始地址（十进制） | 0 |
| 数量 | 该点占字宽（16 位下通常 1；32 位=2） | 1 |
| 小数位数 | 显示保留 0–8 位，留空自动；旧点位表可省略此列 | 2 |

> 导入时会按列定位，回车/换行列请勿多余粘贴。枚举在 Excel 里写字符串 `值=标签;...` 即可（导入解析成内部 enum_json）。

## 5. 「设备信息」sheet

字段/值两列：`设备名 / 连接(RTU:COM6 or ip:port) / 从站 / 扫描间隔ms / 分组数`。导出仅供人读；导入时**忽略**此 sheet（只重建/按分组 sheet 建点位），不覆盖设备的连接参数。

## 6. 手填一个分组 sheet 的空模板（对照它的最小样子）

Excel 新建 sheet（改名成你要的分段，比如 `SYS`），**前 3 行照抄**，第 4 行列头，然后每行填一个点：

```
A:分组      B:SYS
A:从站   B:1    C:功能码  D:3   E:起始地址   F:地址0(该分组首地址)   G:数量  H:按跨度
(空行)
A:别名   B:数据类型  C:单位  D:系数   E:偏移   F:枚举   G:功能码  H:起始地址  I:数量
加热器温度   int16     ℃     0.1     0        (空)      3         0         1
目标转速     uint16    rpm    1       0        (空)      3         1         1
工作模式     int16     (空)   1       0       0=OFF;1=ON  3         2         1
```

「设备信息」sheet 可省略——导入只数**非「设备信息」的 sheet**当分组。所以你不想要设备信息也可以，从来源拷几各分组 sheet 即可组成可导回的"多设备同点位"点表。

## 7. 生成空模板（更快起步）

仓库提供一键生成空模板（「设备信息」+ 一个示例分组 sheet）的脚本：

```bash
npx tsx scripts/new-pointsheet-template.ts
# 生成 docs/pointsheet-template-example.xlsx（+ 同名 .txt 使用说明）
```

想更干净的空白：把该示例里除「设备信息 / SYS」之外的 sheet 都删掉自用即可；或直接 `export_points_xlsx` 一台"没点但有分组"的设备得到空模板壳。

## 8. 端点 / 工具

- Web「实时数据」工具栏：`⬆ 导入点表.xlsx`（上传 xlsx 重建点）、`⬇ 点表.xlsx`（下载）
- REST：
  - `GET  /api/monitor_objects/:id/points/book` → 下载 xlsx
  - `POST /api/monitor_objects/:id/points/book`（body = xlsx 二进制）→ `{groups, registers, errors}`
- MCP：
  - `export_points_xlsx(device_id)` → `{filename, b64, bytes}`
  - `import_points_xlsx(device_id, content_b64)` → `{groups, registers, errors}`

## 9. 行为说明

- 导出带全语义（enum 会写成 `值=标签;…` 字符串，系数/偏移带两位）。
- 导入默认 `replace=true`：先删设备旧全部分组/寄存器，再按每个 sheet 重建为分组和点（X = 全量覆盖）。想追加请不要直接覆盖——要么改另一堆 sheet 全量，要么保留现有设备点位手动加后重新导出。
- 导入后设备会触发 `config/changed`，poller 自动纳入新分组轮询。
- 端到端自检：`npx tsx scripts/test-pointsheet.ts`（导出→导入校验别名/地址/类型/单位/enum/系数/偏移一致）→ `POINTSHEET ROUNDTRIP OK`。


## 10. 图形界面编辑点位语义

设备「实时数据 → 配置」模式中，每个点位右侧提供「点位设置 → 设置」入口，可直接编辑工程单位、系数、偏移和枚举映射。单位留空保存可清除单位；系数默认 1，偏移默认 0，系数必须为非零有限数。枚举按十进制整数原始值匹配，数值不能重复，清空映射并保存会移除枚举。保存通过现有寄存器接口更新配置，不写入设备寄存器；导出的点位表包含这些字段。

物理值换算定义为「原始值 × 系数 + 偏移」。实时表格分别显示原始值与物理值，物理值按系数、偏移计算并追加工程单位。枚举标签仍按原始值匹配；实时曲线、历史表格和历史曲线可切换原始值/物理值；历史物理值使用当前点位配置换算，并非采样时的配置快照。十六进制/二进制格式、无效数据不显示物理值；64 位整数采用整数系数和偏移时精确计算，超出安全整数范围且需要小数换算时显示空值，避免输出不精确的结果。


小数位数可选择自动或 0–8 位，随点位配置保存；仅影响显示，不改变采样数据或曲线计算精度。点位表第 10 列为「小数位数」，留空表示自动；旧版 9 列点位表仍可导入。

实时表格「显示列」可选择地址、类型、原始值、物理值和操作列，并提供精简/全部预设。点位名称始终保留，至少保留一列数值；配置模式会保留类型和设置入口。列选择及曲线显示模式在当前浏览器按设备保存。历史导出仍为原始值。
