# 点位表 XLSX：格式与填写说明

> 版本：v2 · 2026-10-08。使用新版模板，不再支持旧版点位表。

点位表用于导出、编辑并导回一台设备的点位及告警配置。文件按分组组织，列宽、自动换行、冻结表头和筛选便于人工查看。

## 工作簿结构

- **设备信息**：连接参数供参考，导入不修改设备连接。
- **每个分组一页**：点位类型、单位、换算、枚举、显示精度和告警数量。
- **告警规则**：每条告警独占一行，同一点位可以有多条规则。无告警时保留表头。

设备信息和告警规则是保留页名。导出会为每组分配合法唯一页签：必要时清洗、截断或加后缀，也避开History及保留页。原分组名仍完整保存在B1，不能用页签名猜数据库组名。空/纯空白或不能保真表示的名称导出拒绝，请核对或使用JSON备份。

## 点位页

第一行：`分组 | 分组名`。第二行：`从站 | 值 | 功能码 | 值 | 起始地址 | 值 | 数量 | 值`。第三行空白，第四行列头，第五行开始每行一点位。前十列按以下固定顺序填写，不要移动列。

分组从站按现有读取协议填写1–247；导入保留该值，不使用目标设备编号替代。第2行的起始地址/数量是**采样范围**，保留预留头尾和间隙；所有点位的完整dtype字宽必须在其内，越界报错，不自动扩组。两项同时留空时才按点位完整字宽推导并提示；有显式合法范围的空分组可保留。缺从站/功能码沿用旧默认1/FC03并返回warnings，请核对。

| 列 | 名称 | 填写示例与说明 |
|---|---|---|
| A | 别名 | 温度 |
| B | 数据类型 | int16、uint16、float32 等 |
| C | 单位 | ℃、V、rpm；可留空 |
| D | 系数 | 有限数值，可为0或负数；空默认1。物理值 = 原始值 × 系数 + 偏移 |
| E | 偏移 | 0 |
| F | 枚举 | `0=关闭;1=开启`；可留空 |
| G | 功能码 | 3；该点的 Modbus 功能码 |
| H | 起始地址 | 0；十进制地址 |
| I | 数量 | 独立quantity元数据，正安全整数1–9007199254740991；空/缺列默认1，原值保留，不决定dtype字宽或分组范围。长整数请保持文本 |
| J | 小数位数 | 0–8，留空自动；只影响显示 |
| K | 告警数量 | 导出时计算，仅供阅读，修改此列不创建或删除告警 |
| L | 点位标识（可选） | 如p1；全工作簿唯一、区分大小写的1–128位英数/下划线/连字符，非数据库ID；新导出自动填写 |

枚举按解码后的整数原始值匹配，不应用系数与偏移。历史物理值按当前配置换算。曲线和采样不因显示小数位数而舍入。

## 告警规则页

第一行前六列保持固定，第二行开始每行一条规则。v2可选G列「点位工作表」引用实际页签，可选H列「点位标识」引用点位L列，新导出自动填写。旧六/七列仍只在给出的定位条件唯一时兼容。不使用内部数据库ID，便于复制到另一台设备。

| 分组 | 功能码 | 起始地址 | 告警条件 | 原始值阈值 | 告警提示 | 点位工作表 | 点位标识 |
|---|---|---|---|---|---|---|---|
| SYS | 3 | 0 | >= | 800 | 温度过高 | SYS | p1 |
| SYS | 3 | 0 | < | 0 | 温度过低 | SYS | p1 |

- 条件支持 `>`、`>=`、`==`、`<=`、`<`、`!=`，也接受 ≥、≤、=、≠。
- 阈值必须是有限数字，允许负数和小数。比较对象是按点位类型解码后的**原始值**，不应用工程换算或显示舍入。
- 提示可留空，最多 200 个字符。
- 原始组名、功能码、地址、页签引用（若填）和点位标识（若填）必须共同对应唯一点位。组名及点位ID字符精确匹配，不裁剪空格；改页签同步G、改组名同步A、改点位ID同步H。引用错误不回退首项。同页同址多定义带告警需填写L/H；一个点位的多条规则使用同一ID。
- 整行排序不依赖行号；复制点位行需换全文件唯一的L标识并明确同步相关H。标识仅本文件有效，导入不保存它，重新导出可重新分配；不能当作数据库register_id。旧无标识的同址歧义文件仍拒绝，不按别名或dtype猜归属。
- 新增一行创建规则，删除一行移除规则。同一点位多条规则直接填写多行，不需要 JSON。
- 导入前检查所有告警行；格式错误或找不到点位时，返回行号错误并保留原有配置。

界面入口：设备「实时数据 → 配置」，点击具体点位的「告警」。触发时顶部显示告警、原始值和物理值标红；恢复后取消标红。数据过期、采集暂停或通信异常时不判断为当前告警。

## 导入与导出

Web：设备「实时数据 → 配置」工具栏的「导入点位」「导出点位」。

- REST：`GET /api/monitor_objects/:id/points/book` 下载；`POST` 同一路径上传 XLSX 二进制。
- MCP：`export_points_xlsx(device_id)` / `import_points_xlsx(device_id, content_b64)`。

导入默认**全量重建目标设备的分组、点位和告警**，会移除文件中没有保留的旧配置。请先导出备份，再编辑并导回。设备连接参数保持不变。新版模板必须保留「告警规则」页，无规则时只留表头。

先校验整本工作簿再事务重建，字段/范围/定位错误或数据库写入失败保留原配置；没有分组页不会清空设备。只建文件中明确的点，不补占位行。返回errors需处理，warnings也可能表示使用旧默认/推导范围/组名回退或已提交但通知/日志失败，不能一律当作已回滚并重试。[字段规则](../develop/09-XLSX点表字段保真.md)、[页签规则](../develop/10-XLSX工作表名称与告警定位.md)及[文件内身份](../develop/11-XLSX文件内点位标识.md)说明兼容边界。旧应用不理解这些扩展，不能保证它能处理同名/同址多定义新文件。

## 生成模板与验证

```bash
npx tsx scripts/new-pointsheet-template.ts
npx tsx scripts/test-pointsheet.ts
```

模板输出到 `docs/pointsheet-template-example.xlsx`，另附同名 TXT 说明。模板包含两条温度告警示例，正式使用前请按设备原始值量程修改或删除。

图形界面的点位「设置」可编辑单位、系数、偏移、枚举及小数位数；这些配置随点位表一起交换。
