### 4.1 验证结果 ✅（含 1 处小问题）

| UI 创建 RTU 设备 → 列表 3 台 → 删除 → 恢复 2 台 | ✅ |
| 设备主视图对 RTU 显示 serialPath | ✅（`App.tsx` 第 428 行） |

### 4.2 🟡 小问题：侧栏设备列表对 RTU 显示为空端口

- **现象**：左侧设备列表 `App.tsx` 第 371 行固定显示 `{ip}:{port}`，RTU 设备 ip 为空 → 显示成 `:502`，而不是串口路径（主视图已正确显示 `COM7`）。
- **建议**：侧栏与主视图统一，RTU 设备显示 `serialPath`（或「RTU · COM7」）。

### 4.3 规格文档需更新

产品规格书 `02-产品规格书.md` §5.4 仅写「Modbus TCP」，§5.1 设备模型仅 `mode(master|slave)`，未含 RTU 的 `transport(tcp|rtu)` 与串口参数（serialPath/baudRate/parity/stopBits/dataBits/flowControl）——建议补入。
