## 复测明细

### 1. 加载与基础（回归）✅
HTTP 200、2 台设备、侧栏可见「新建设备」按钮。

### 2. 控制台 / 资源 / 压缩 ✅
- console.error **0**、未捕获异常 **0**、失败请求 **0**、4xx/5xx **0**。
- JS 资源 `Content-Encoding: zstd`（压缩已生效；zstd 优于 gzip，本地影响可忽略）。

### 3. 历史多分组对齐（P0）✅
- 历史表 21 列（时间 + 20 寄存器）。
- **最近 5 分钟**查询：首行/末行 `—` 均为 **0**，两组值同列对齐显示。
- 根因修复在后端 poller：单一全局轮询循环 + 同周期共享 `cycleTs` 时间戳，两组寄存器时间戳完全对齐（`addr0` 与 `addr4096` 时间戳一致）。
- ⚠️ 说明：默认「最近 1 小时」查询的**开头部分**若包含修复前采集的旧数据，旧行仍会显示 `—`（旧数据时间戳本身未对齐，无法回溯修复）——属预期现象，非缺陷。

### 4. 删除确认（P1）✅
新建临时设备 → 点删除 → 弹确认框 → 拒绝（设备保留）→ 再删 → 接受（设备删除），全流程正确，无副作用。

### 5. 写寄存器校验与反馈（P1）✅
空值 / 非法数字均被拦截并给出中文提示，合法值写入后显示「已写入」并自动关闭，无未处理异常。

### 6. 移动端（P2）✅（含一处可继续优化）
- 主区宽 375px（满宽），不再被侧栏挤成 111px；表格 min-width 440px、主区可横向滚动。
- 遗留小建议：手机端侧栏仍是 264px 的 `position:fixed` 抽屉，**默认覆盖在内容上方**，需手动点「«」收起。建议手机端默认收起侧栏 + 加汉堡按钮/点击遮罩关闭，体验更完整（非阻塞缺陷）。

### 7. 性能（回归）✅
TTFB 3ms、DCL 40ms、load 40ms，与上轮基本一致，无退化。
