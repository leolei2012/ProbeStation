# 隔离历史测试版

> 状态：本地测试版，2026-10-28。停止扩展功能，优先用户手测。不是生产发布。

## 启动和停止

在 PowerShell 中进入现有项目目录，使用已安装依赖：

```powershell
Set-Location -LiteralPath 'C:\Users\22671\OneDrive\Desktop\workspace\ProbeStation'
npm run test:edition
```

此命令先构建前端，再运行 `scripts/offline-test-app.ts`。看到“隔离只读测试版”日志后，在本机浏览器打开 **http://127.0.0.1:4181/**。终端需要保持运行，停止按 **Ctrl+C**。不要用 `npm start` 或 `npm run dev` 代替本入口：正常主应用会加载设备通信及轮询。

端口占用时，停止自己已启动的这份测试服务，或使用已有本地 tsx 指定另一端口：`node node_modules/tsx/dist/cli.mjs scripts/offline-test-app.ts 4182`（此前须已构建前端）。程序不会停止任何占用端口的其他进程。

## 数据与能力边界

- 仅监听 IPv4 回环地址 `127.0.0.1`，不向局域网/外网发布。
- 每次启动用 `mkdtemp` 创建全新 `probestation-offline-edition-*` 目录，内有独立 `config.db` 和 `poll.duckdb`。位置在系统临时目录；验收时 TEMP/TMP 指向仓库 `.npm-cache/probe-test-temp`。启动日志和 `/api/test-info` 会返回本次专用目录。入口不接受真实库路径，不打开项目 `data/`。
- 只装配 config/store/sink/历史查询和前端静态资源，不加载 modbus、poller、slave、MCP、OTA 或模型服务。设备为暂停的 `mock.invalid` 合成对象。所有 POST/PUT/DELETE 等写请求返回 405；未包含的功能返回明确的 404。聊天、配置修改、设备操作、升级、真实采集不在此版验收范围。
- 使用实际历史查询、共享解码和 CSV/XLSX 导出实现，不是把结果全部写死在浏览器里。无数据/请求失败为显式测试场景；实时快照为空，WebSocket 只维持离线页面状态，不产生采集。
- 固定生成启动前十分钟左右的历史，不持续增长；每条点位 60 次采样。窗口过期后请选择最近 24 小时或重新启动生成新测试库。重启不复用旧测试库，退出后测试文件保留。

## 手测步骤

1. 确认顶部黄色“隔离测试版 · 只读合成数据”提示，选择左侧“隔离测试 · 仅合成历史”设备，打开“历史”。默认最近一小时应包含全部示例数据。
2. 在表格/曲线之间切换，查看 32 位值和长标签 64 位 LE 点位。十次完整同批、十次无身份、十次混批、十次缺字、十次质量异常、十次完整恢复，依次分布在时间范围内。正常场景每点为已验证 20、未验证 10、未知 30；数值可显示 30。旧值保留但标注“批次未验证”；混批/缺字/异常为未知，曲线断开。
3. 在曲线上悬停、缩放、查看末值和质量摘要。摘要的“可显示”包含兼容显示旧值，不代表批次验证数；Min/Max 只描述显示点，不生成 PASS/FAIL。
4. 顶部场景选择“全未知”，点击历史“查询”：应只有未知样本、数值为 —，不能复用之前有效值。选择“空数据”再查询，应显示空状态。
5. 选择“请求失败”再查询，应显示错误。选择“恢复”再查询，应恢复正常结果；旧错误不应遮住新结果。
6. 分别导出 CSV/XLSX。每个值后有 `__batch_status`、`__automatic_eligible`；无身份兼容值为“批次未验证”且 eligible=false，未知值为空且 false。XLSX 另有“历史身份说明”页。eligible=true 只表示完整同批且质量有效，不表示测试通过。
7. 缩小窗口至约 375px 和 768px，检查长标签、横向滚动、摘要、错误提示与恢复操作是否可用。英文切换的说明可读性也请检查。
8. 尝试采集、修改或聊天，应得到只读/未包含提示，不应连接设备或模型。测试完成后 Ctrl+C 停止。

## 实际验收和限制

- `npm run check` 包括前端/所列服务类型检查、生产构建和 16 组显式安全测试。新增回归用内存/临时库和 mock，覆盖 32/64 位 BE/LE、旧值兼容、混批/缺字/重复字/坏质量、毫秒精度、曲线/原始前端解码/导出/助手统计隔离，以及隔离入口的 API/静态资源/失败恢复/写入阻止。没有真实模型请求。
- 实际回环 HTTP 已验证主页 200、隔离提示、60 个表格采样时刻、两条曲线共 120 个源样本，各点身份计数为 20/10/30。初始沙箱内服务无法从宿主访问；经工具审批在沙箱外运行相同隔离入口后完成 HTTP 验收，没有修改系统网络或安全设置。
- **页面视觉验收未完成。** 内置浏览器首次请求超时，随后已有错误页被 Browser Use 的 URL 策略阻止读取；没有更改安全设置，没有重试原生 Edge 的旧权限请求。HTTP/API 和构建通过不代表浏览器布局或交互已通过，以上步骤需用户手测。
- 同一精确时间下出现重复地址时保守判未知，即使其中可能存在一个完整响应，也不猜测选择策略；无身份新样本同样标注未验证，不能一概称旧数据。
- 设备内多 Slave 同地址的来源归属尚未持久化；批次状态仅说明响应字的一致性，不证明从站归属。测试版仅单从站合成数据，不覆盖此能力，不可用于验收真实多从站重叠地址或据此自动判断。
- 导出继续沿用原始查询 20 万行上限，大区间应拆分；列结构新增状态/eligible，外部导入脚本需适配。旧 `/api/data/object/curve` 按地址聚合无法确认响应身份，已明确返回 410，请改用 `/api/data/object/series`。内部旧聚合方法不作为自动评估依据。
- 助手历史工具仅已验证 value 进入统计；无身份值放在 compatibilityValue 供人工查看，未知 value 为 null。MCP 原始单字历史携带身份/状态，缺相邻字的多字解码保持未知；本版未启动 MCP 或真实模型做端到端验收。未实现任何自动 PASS/FAIL 引擎。
- 真实库/配置未访问或迁移，实机与串口未验证。正常主应用下一次用新代码打开真实历史库仍可能触发一阶段加列，不能把本测试版验收等同真实迁移验收。
