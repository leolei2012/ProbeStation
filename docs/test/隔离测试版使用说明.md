# 隔离历史测试版

> 状态：本地隔离测试版，更新于 2026-11-06。不是生产发布；新交互仍需用户手测。

## 启动和停止

在 PowerShell 中进入现有项目目录，使用已安装依赖：

```powershell
Set-Location -LiteralPath 'C:\Users\22671\OneDrive\Desktop\workspace\ProbeStation'
npm run test:edition
```

此命令先构建前端，再运行 `scripts/offline-test-app.ts`。看到“隔离只读测试版”日志后，在本机浏览器打开 **http://127.0.0.1:4181/**。终端需要保持运行，停止按 **Ctrl+C**。不要用 `npm start` 或 `npm run dev` 代替本入口：正常主应用会加载设备通信及轮询。

端口占用时，停止自己已启动的这份测试服务，或使用已有本地 tsx 指定另一端口：`node node_modules/tsx/dist/cli.mjs scripts/offline-test-app.ts 4182`（此前须已构建前端）。程序不会停止任何占用端口的其他进程。

## 数据与能力边界

- 仅监听 IPv4 回环地址 `127.0.0.1`，不向局域网/外网发布。
- 每次启动用 `mkdtemp` 创建全新 `probestation-offline-edition-*` 目录，内有独立 `config.db` 和 `poll.duckdb`。位置在系统临时目录；验收时 TEMP/TMP 指向仓库 `.npm-cache/probe-test-temp`。启动日志和 `/api/test-info` 会返回本次专用目录。入口不接受真实库路径，不打开项目 `data/`。
- 只装配 config/store/sink/历史查询和前端静态资源，不加载 modbus、poller、slave、MCP、OTA 或模型服务。设备为暂停的 `mock.invalid` 合成对象。所有 POST/PUT/DELETE 等写请求返回 405；未包含的功能返回明确的 404。聊天、配置修改、设备操作、升级、真实采集不在此版验收范围。串口选择例外仅开放后端系统元数据枚举：来自真实后端电脑，source=system，不会打开端口。
- 使用实际历史查询、共享解码和 CSV/XLSX 导出实现，不是把结果全部写死在浏览器里。无数据/请求失败为显式测试场景；实时快照为空，WebSocket 只维持离线页面状态，不产生采集。
- 固定生成启动前十分钟左右的历史，不持续增长；每条点位 60 次采样。窗口过期后请选择最近 24 小时或重新启动生成新测试库。重启不复用旧测试库，退出后测试文件保留。

## 手测步骤

1. 确认顶部黄色“隔离测试版 · 只读合成数据”提示，选择左侧“隔离测试 · 仅合成历史”设备，打开“历史”。默认最近一小时应包含全部示例数据。
2. 在表格/曲线之间切换，查看 32 位值和长标签 64 位 LE 点位。十次完整同批、十次无身份、十次混批、十次缺字、十次质量异常、十次完整恢复，依次分布在时间范围内。正常场景每点为已验证 20、未验证 10、未知 30；数值可显示 30。旧值保留但标注“批次未验证”；混批/缺字/异常为未知，曲线断开。
3. 在曲线上悬停、缩放、查看末值和质量摘要。摘要的“可显示”包含兼容显示旧值，不代表批次验证数；Min/Max 只描述显示点，不生成 PASS/FAIL。
4. 顶部场景选择“全未知”，点击历史“查询”：应只有未知样本、数值为 —，不能复用之前有效值。选择“空数据”再查询，应显示空状态。
5. 选择“请求失败”再查询，应显示错误。选择“恢复”再查询，应恢复正常结果；旧错误不应遮住新结果。
6. 分别导出 CSV/XLSX。每个值后有 `__batch_status`、`__automatic_eligible`；无身份兼容值为“批次未验证”且 eligible=false，未知值为空且 false。XLSX 另有“历史身份说明”页。eligible=true 只表示完整同批且质量有效，不表示测试通过。
7. 缩小窗口至约 375px 和 768px，检查长标签、横向滚动、摘要、错误提示与恢复操作是否可用。英文切换的说明可读性也请检查。
8. 尝试采集、修改或聊天，应得到只读/未包含提示，不应连接设备或模型。测试完成后 Ctrl+C 停止。

## 实际验收和限制

- `npm run check` 包括前端/所列服务类型检查、生产构建和 29 组显式安全测试。新增回归用内存/临时库和 mock，覆盖 32/64 位 BE/LE、旧值兼容、混批/缺字/重复字/坏质量、毫秒精度、曲线/原始前端解码/导出/助手统计隔离，以及隔离入口的 API/静态资源/失败恢复/写入阻止。新增历史请求生命周期与导出回归覆盖取消、超时、恢复、精确缩放区间和原始导出。没有真实模型请求。
- 实际回环 HTTP 已验证主页 200、隔离提示、60 个表格采样时刻、两条曲线共 120 个源样本，各点身份计数为 20/10/30。初始沙箱内服务无法从宿主访问；经工具审批在沙箱外运行相同隔离入口后完成 HTTP 验收，没有修改系统网络或安全设置。
- **页面视觉验收未完成。** 内置浏览器首次请求超时，随后已有错误页被 Browser Use 的 URL 策略阻止读取；没有更改安全设置，没有重试原生 Edge 的旧权限请求。HTTP/API 和构建通过不代表浏览器布局或交互已通过，以上步骤需用户手测。
- 同一精确时间下出现重复地址时保守判未知，即使其中可能存在一个完整响应，也不猜测选择策略；无身份新样本同样标注未验证，不能一概称旧数据。
- 新采样已持久化请求目标从站，曲线/表格/导出/助手按目标来源及完整批次验证；旧 NULL 来源仅兼容查看，跨来源同址不能归属时未知。test-source-pipeline 用内存库验证同毫秒不同来源等案例，test-mcp-source 测试只读 handler。测试版页面仍为单从站合成数据，不能替代真实多从站设备验收。
- 导出继续沿用原始查询 20 万行上限，大区间应拆分；列结构新增状态/eligible，外部导入脚本需适配。旧 `/api/data/object/curve` 按地址聚合无法确认响应身份，已明确返回 410，请改用 `/api/data/object/series`。内部旧聚合方法也已停用并抛错。
- 助手历史工具仅已验证 value 进入统计；无身份值放在 compatibilityValue 供人工查看，未知 value 为 null。MCP 原始单字历史携带身份/状态，缺相邻字的多字解码保持未知；本版未启动 MCP 或真实模型做端到端验收。未实现任何自动 PASS/FAIL 引擎。
- 真实库/配置未访问或迁移，实机与串口未验证。正常主应用下一次用新代码打开真实历史库仍可能触发一阶段加列，不能把本测试版验收等同真实迁移验收。

## 串口清单手测（2026-10-28）

刷新页面后，点击新增设备或设备编辑，选择 RTU（串口），在“连接参数 / Connection”检查“系统可发现串口”和原“串口路径”框。点击刷新重新枚举后端电脑系统可发现的全部串口；这不是已配置设备列表，也不是浏览器 Web Serial，远程访问时列出的是运行后端的电脑。

先输入 COM14 或一个自定义路径，再刷新：已填路径不应被替换，即使它不在系统清单中，也应保留为“当前/手工值”。选择某个发现的端口后，原输入框应得到对应路径，不应保存包含厂商/描述的标签文字。可继续手工修改。枚举不检查端口是否忙或能够通信，清单中有端口不表示已连接。

没有端口时应有空列表提示；读取失败应有重试提示，保留此前清单但标明可能过时，并保留已填路径。加载时有进度提示，刷新按钮禁用，手工输入仍可用。可手动取消弹窗重新打开。测试版的保存/连接仍被禁止，关闭或取消即可，不要期待保存到真实配置。

测试版清单默认来自后端真实系统，页面明确标注仅枚举；自动回归的模拟清单带 source=mock 并验证“模拟端口清单，不是实机端口”提示。自动回归替换 native list/open，不枚举或打开真实端口；本机 HTTP 验收仅调用系统 list，绝不调用 open、connect、read、write 或扫描握手。

本轮已在独立 Edge 扩展标签页实测串口控件：显示系统发现的 COM7，手填 COM14 后刷新不变，选择 COM7 时只写入路径。没有点击保存或连接。截图采集超时，无像素截图验收；空/失败状态的覆盖来自 mock/API/SSR 回归。用户原 localhost:9090 主应用未被重启，不能保证旧后端已有新接口；先使用 4181 验收。

## 历史查询恢复手测（2026-11-06）

仅在隔离测试版中测试。历史表格和曲线查询期间应出现“取消查询”；取消后显示已取消，查询按钮恢复可用，再查询应恢复结果。改变时间区间或切换表格/曲线，会取消过时请求，不应被迟到的旧结果覆盖。取消的是浏览器查询，不是设备采集。

选择顶部“慢查询/导出（模拟）”，请求会延迟 3 秒，便于点击取消；也可使用浏览器开发工具限速。真实等待超过 30 秒时，应显示“查询超过 30 秒，请缩小时间范围后重试”，而非无限“查询中”；网络超时由纯 mock 自动回归验证，本轮没有实际浏览器验收。选择顶部“请求失败”后查询应出现 503；改为“恢复”后重试应正常。空数据仍应明确显示空状态，不复用旧曲线。

本轮工具没有浏览器控制入口，也未发现已安装 Playwright CLI；没有安装工具或重试以前受限的原生 Edge。类型检查、构建和 API/mock 测试通过，不表示布局、键盘交互、窄屏已实际验证。

## 缩放区间导出手测（2026-11-06）

1. 在合成设备的历史曲线中查询最近一小时。未做时间缩放时，“导出当前缩放区间”禁用；“导出完整时间范围”可用。
2. 放大或横向框选一段有数据的区间，等待查询完成；点击“导出当前缩放区间”。弹窗应显示该区间的起止时间（含毫秒）、UTC 偏移和已选点位数。取消/Escape 应关闭弹窗并返回触发按钮，Tab 不应移到弹窗外。
3. 分别下载 CSV/XLSX，确认行时间均在弹窗范围内，只有所选点位及批次状态/资格列。图例隐藏或 Y 轴放大不应改变时间范围或已选点位；下载的是合成库里的原始历史行，不是屏幕上保留的峰谷点。
4. 再用“导出完整时间范围”，弹窗应回到顶部输入框的完整区间。重置时间缩放后，缩放导出按钮应禁用。清空点位选择后两个导出入口均应禁用，不应导出全设备点位。
5. 物理值视图中的导出仍是原始历史，弹窗会说明。空区间导出应只有表头，不能带上次结果；上限为 20 万条所选点位所需原始行；未选地址不占用限额，超过时请减少点位或缩小范围，不应收到部分文件。
6. 在中文/英文、375px/768px 宽度检查两个导出入口、弹窗时间换行、取消与下载；下载准备期间应有状态提示，取消后不得保存迟到文件；成功下载走普通下载流程，不应另开 JSON 错误标签页。不要改变系统安全设置。

本阶段通过新临时库中的 API/文件内容与 SSR 检查，尚无实际浏览器下载、焦点、布局验收；此区别不因构建成功而改变。没有操作实机或运行中的 9090 实例。


## 导出超限与取消手测（2026-11-06，阶段三）

1. 正常查询合成历史后，选择顶部“导出超限（模拟）”，打开任意导出弹窗，再选 CSV/XLSX。应在弹窗内看到“超过 200000 条原始行、停止生成文件”的提示，没有下载、没有 JSON/HTML 伪表格。该场景只模拟超限响应，合成库并非真的有 20 万条数据。
2. 取消弹窗，切换“恢复”，重新打开导出并下载，应正常成功。完整范围和缩放范围均可测试；前两阶段的范围/点位快照仍应准确。
3. 选择“慢查询/导出（模拟）”，点击查询后 3 秒内取消，再等响应完成，应保持已取消；随后重试可恢复。导出准备期间点击取消或 Escape，再等 3 秒，不应产生迟到文件。
4. 选择“请求失败”测试导出 503 提示及重试；下载按钮准备时禁用，取消保持可用。分别检查中文/英文、键盘 Tab/Escape 与窄屏。
5. 低于、等于、超过真实 200000 条原始行的边界由内存 DuckDB/API 自动测试覆盖；不要为手测写入真实数据库或采集更多实机数据。普通历史原始查询上限仍为 200000，额外一条仅用于导出完整性判断。

本轮仍没有实际浏览器执行工具；上述为待执行的手测步骤，不是 UI 验收记录。已完成的是纯内存/临时库和 mock/API 检查，没有启动或重启任何采集服务。


## 按所选点位导出手测（2026-11-06，阶段四）

在正常/恢复场景中，只选择一个点位导出，再选两个点位导出，检查列、时间范围和批次状态。所需字按点位 dtype 宽度读取；多字类型不能只读起始地址，缺字或混批仍须未知。只包含未选点位原始字的时刻，不应再生成全空行。上限按筛选后的所需原始字计算，重叠地址范围不重复读取，实际重复采样不被静默删除。

隔离示例两点位通常同一时刻采样，筛选限额的关键场景由 `test-export-selection` 的真实内存库 200001 条未选原始行与目标点位回归覆盖。不要往真实库造数据。“导出超限（模拟）”始终模拟 413，不会因减少点位自动解除；需切换“恢复”测试成功路径。此阶段未完成实际浏览器验收，也没有更新运行中的 9090 实例。
